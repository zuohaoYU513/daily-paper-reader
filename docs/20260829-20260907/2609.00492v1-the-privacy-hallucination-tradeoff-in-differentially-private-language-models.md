## 摘要
在医疗等高风险领域，隐私和事实准确性都至关重要。令人担忧的是，我们揭示并研究了差分隐私（DP）语言模型中的隐私-幻觉权衡。首先，我们通过实验证明，使用DP预训练或微调的模型比非DP模型更容易产生幻觉，且随着隐私预算越严格，严重程度越高。其次，我们研究了驱动这种权衡的模型属性，证明DP机制会 flatten 输出分布，可能将概率质量重新分配给事实上不正确的替代项。第三，通过控制训练数据中事实频率的实验，我们描述了信息频率如何降低DP模型中的幻觉风险。总体而言，我们的发现强调了需要更细致的隐私保护干预措施，在不损害事实准确性的前提下提供严格的隐私保证。

## Abstract
Both privacy and factual accuracy are paramount in high-stakes domains like healthcare. Concerningly, we uncover and investigate a privacy-hallucination tradeoff in differentially private (DP) language models. First, we empirically show that models pre-trained or fine-tuned with DP tend to produce more hallucinations than non-DP counterparts, with increased severity as the privacy budget grows stricter. Second, we investigate model properties driving this tradeoff, demonstrating that DP mechanisms flatten output distributions, potentially redistributing probability mass toward factually incorrect alternatives. Third, through experiments where we control fact frequency in training data, we characterize how information frequency can reduce hallucination risks in DP models. Overall, our findings underscore the need for more nuanced privacy-preserving interventions that offer rigorous privacy guarantees without compromising factual accuracy.

## 2. 方法论

- **核心思想**：将“隐私-幻觉权衡”拆解为三个可操作的研究问题，并要求实验设置满足严格的数据隔离条件，以杜绝预训练数据与微调数据重叠对 DP 保证和评测有效性的污染。
- **DP 训练方式**：
  - **DP 微调**：使用 DP-SGD（差分隐私随机梯度下降）配合 LoRA 低秩适配器，在 GPT-J 6B（其预训练语料 The Pile 完全公开、截止日期已知）上进行微调。使用 PLD 隐私会计师跟踪隐私预算 ε ∈ {8, 16}，δ = n⁻¹·¹。
  - **DP 预训练**：使用 Google 团队发布的 VaultGemma-1B（ε=2，与 Gemma2 共享预训练数据混合，但采用 DP-SGD 从头预训练），并与多个非 DP 对照模型做二手数据比较。
- **幻觉定义与量化**：
  - 定义：生成训练数据（预训练或微调语料）中不存在的、不被支持的事实性陈述即为幻觉。
  - 评估方式：
    - **FactScore 自动化评估**：将生成的文本用 LLM 分解为原子声明，随后以对应 Wikipedia 原文作为知识源对每条声明进行独立的事实核验（使用 BM25 检索 + Llama-3.1-8B-Instruct 判断），并以 CORE 模块过滤冗余声明。得分即事实正确的声明比例。
    - **人类评估**：招募 5 名 CS 研究生，对 Wikipedia AI 文章生成的声明进行正确性、来源支持度和质量问题标注（Cohen's κ = 0.57–0.84，标注者间一致性为中等至强）。
- **机制分析（RQ2）**：
  - 以 Kalai & Vempala 的“校准模型必然产生幻觉”理论（f_gen ⪆ d_MF − Mis(g,p)）为基本框架，解释 DP 噪声作为非目标性干预如何将概率质量从观察到的高置信事实分散到未观察的替代项上。
  - 设计一个可控的 **bigram 合成实验**：模拟 25,000 个可能的三元组事实（Person-Food-Place），将其中 2,000 个标记为真实事实，频率服从 Pareto 分布（可控制单调事实率 d_MF）。对比了两种干预：基于选择性上采样/重复目标事实的目标性校准（upweighting）和基于 Laplacian 噪声的 DP 干预。结果表明：目标性上采样可轻微降低幻觉，而 DP 噪声则单调地增加幻觉。
  - 在真实 LLM 上，用**核大小（nucleus size）**和**有效词表大小 exp(H)** 两个指标来度量输出分布的扁平化程度（熵增效应），发现 DP 模型的熵显著高于非 DP 模型。
- **事实频率分析（RQ3）**：
  - 合成受控实验：构造虚构实体三元组事实（如“the capital of [zephyria] is [mordath]”），每个事实按 1/3/7/15/30/60 次/epoch 的频率出现（训练 15 epochs），在预训练 GPT-2 和随机初始化 GPT-2 两种设置上施加 DP-SGD（噪声乘子 σ∈{0,0.1,0.3,0.5,0.7,1.0}，对应 ε∈{∞,1311,108,30,13,6}），测量事实前缀下正确补全的条件概率 P(correct completion)。
  - 核心问题：在什么重复频率条件下，DP 模型才能学会事实？

## 3. 实验设计

## 5. 实验数量与充分性评估

- **实验数量**：实验覆盖多种设置，包括（a）DP 微调在 2 个主要评测集上的多个隐私预算与基线对照；（b）DP 预训练在 3 个评测集上的跨模型对比；（c）多个温度（0.3–1.0）的分布分析；（d）bigram 合成实验；（e）合成事实频率受控实验（预训练 + 随机初始化的 GPT-2 × 6 个噪声档位 × 15 epochs）；（f）ANADP 自适应噪声基线；（g）重复性幻觉聚类分析；（h）人类评估的分层抽样验证；（i）多个 LLM 评测器的鲁棒性检验。总体来看，实验量较大且覆盖面广。
- **统计分析充分性**：主体结论（DP 增加幻觉、分布扁平化、频率阈值增加）均有多重统计检验（响应级 + 主题级）支撑。预训练数据上的 KDE 分布与中位数差异也一目了然。由此可判断，结论具有较强统计稳健性。
- **客观性评估**：论文在评测时采用多种 LLM 作为核验器（Llama-3.1-8B 为主，DeepSeek-R1-Distill-Qwen-7B、Llama-3.2-3B 为验证）和人工标注双重评估；承认自动化指标与人工判断之间存在中等偏差（model-human κ = 0.23–0.49），不掩盖评估噪声。
- **一个公平性风险**：DP 预训练场景因成本所限无法做数据完全匹配的对照实验；论文对此有清晰说明，且通过引入与 VaultGemma 数据匹配的 Gemma2-2B 和知识截止于 2019 年（几乎不可能涵盖评测资料）的 GPT-2 XL，将"数据不匹配"的影响限制在可解释范围。DP 微调场景则用公开语料构建数据隔离良好的干净对照，消除数据重叠的干扰。
- **充分性小结**：针对以资源受限学术团队可完成的实验范围，实验数量与设计是相当充分且严谨的。

## 6. 主要结论

- **结论一（RQ1）**：无论 DP 以微调还是预训练形式作用，都会显著增加模型幻觉。隐私预算越严格（ε 越小），幻觉率越高、FactScore 分布越左移。在基于预训练数据的评测中该效应更严重，DP 预训练模型（VaultGemma）的 FactScore 甚至和从未见过目标文章的 GPT-2 XL（知识截止 2019）相当。
- **结论二（RQ2）**：DP 的核心机制缺陷在于其噪声是一种**非目标性的分布扰动**：它使预测分布熵增大、有效词表扩大（核尺寸 ~100–400 tokens），将原本集中在正确备选上的概率质量分散到大量（且往往是错误的）候选词上；在 unseen 数据上 token 排序发生改变，故幻觉不是随机噪声而是系统性反复的错误映射。
- **结论三（RQ3）**：事实要避免被 DP 模型“遗忘/无法学习”，需要满足相当高的重复频率阈值。在非 DP 下 1 次/epoch 即可学会的事实，在 ε≈1311 时需要 30 次/epoch，在 ε≈30 时需要 60 次/epoch；在 ε ≤ 13 时即使 60 次/epoch 也无法被学会。对随机初始化模型（DP 预训练模拟）而言阈值更为苛刻。此外，增加事实在训练集中的重复频次（信息频率）可以部分抵消 DP 带来的幻觉风险。
- **结论四**：传统的困惑度/训练损失等效用指标**不能反映幻觉问题**——DP 模型甚至能获得比非 DP 模型更低的困惑度，但其事实分数却偏低。这直接反驳了单纯用困惑度论证 DP 可用性的做法。
- **结论五**：ANADP（自适应各向异性噪声分配）的标准 DP 隐私证明不成立且无法在经验上缓解隐私-幻觉权衡。

## 7. 优点

- **数据隔离设计的严谨性**：选用 GPT-J 6B 并严格选取 2020 年之后创建的 Wikipedia 文章，从而保证微调数据虽然“词语模式重叠”，但“文档/资料单元从未出现在预训练语料中”，这是做好 DP 场景评测的关键前提。对 Wikipedia AI 与 Science 文章的构造，能够回答“DP 在不泄露个体级别数据的前提下能否模型化跨越多次出现的事实”这类问题。
- **多指标与方法互补性**：将 FactScore 自动化评测与人工标注结合，以多种 LLM 作为核验器、多温度下的 KDE 分布、显著性统计检验，保证结论稳健。
- **机制的可解释性**：用 bigram 受控实验将“选择性上采样”（集中概率质量）与“DP 噪声”（发散概率质量）精确分离，清晰展示了 DP 不是简单的“降置信”，而是把概率质量移到“错误替代项”上的过程。
- **频率受控的实验框架**：用合成虚构事实追踪模型的习得阈值，同时考虑预训练与随机初始化的初始化差异，结论兼具清晰度与可推广性。
- **对“低困惑度等于高质量”的判误进行的厘清**，直接惩罚了只用困惑度评估 DP LLM 的主流偏好。
- **诚实的局限说明**：论文明确承认 VaultGemma 数据匹配不完美、未探讨缓解幻觉的专用方法、未涉足其他 DP 模式（如 RAG-DP）等。

## 8. 不足与局限

- **实验模型规模相对有限**：核心受控实验主要在 GPT-J 6B（微调）与 GPT-2（合成事实频率实验）上开展，未验证在更大规模模型（如 70B 级别）上的表现和经济性。
- **未能实现完全数据匹配的 DP 预训练对照**：受算力限制，VaultGemma 与 Gemma 各模型的预训练数据混合、tokenizer、模型结构均存在差异，因此对 DP 预训练的结论并非理想条件下的受控实验证据。
- **数据集单一性**：尽管 Wikipedia 适合事实核验，但其语言风格与医疗记录、法律文档等内容仍有差距。论文说明了选用维基百科的原因，但没有补充更多高风险领域内的私有/域内语料实验。
- **未探索缓解手段**：论文没有研究（也声明这不属于研究范围）如何通过校准推理、显式不确定性表达、拒绝生成等策略来消减 DP 模型的幻觉风险；这意味着“DP 模型可以安全地表示‘我不知道’”这一可能性并未被讨论或验证。
- **其他相关 DP 范式未覆盖**：如 DP 检索增强生成、DP 解码、DP 合成数据等；这些范式是否继承同样幻觉模式仍未可知。
- **对更多参数的敏感度分析不足**：虽然研究了频率与噪声幅度的关系，但对 DP-SGD 中的其他超参数组合（裁剪阈值 C、批大小、学习率、LoRA 秩等）的交互探讨有限。
- **自动化评估本身的不完美性**：论文承认 LLM 作为事实核验器存在与人类判断不一致的地方，并观察到对“支持性”的判断模型与人类之间一致性较低。该事实降低了 FactScore 数值的绝对可信度，也会给结论带来一定程度的偏差风险。
