## 摘要
大型视觉-语言模型（LVLMs）已取得强大的多模态性能，但确保生成内容的事实正确性仍具挑战性。现有的提供事实性统计保证的方法通常依赖外部验证器或生成时的置信度信号，这引入了辅助依赖性，或对于置信但错误的输出往往失效。我们认为，可靠的事实性控制可以通过从模型自身获得的内省信号来实现。我们引入了IntroConformal，这是一个无需训练的共形风险控制（CRC）框架，提供有限样本、无分布假设的事实性保证。我们首先用逐层语义稳定性来实例化它，这是一种从隐藏状态表示导出的共形分数，然后提出验证概率，这是一种更强的分数，捕捉模型对声明事实性的自我管理判断。在多种LVLM架构上，IntroConformal满足共形风险保证，同时显著减少弃权，并相对于基于外部验证器的基线实现具有竞争力或更优的声明级别区分。

## Abstract
Large Vision-Language Models (LVLMs) have achieved strong multimodal performance, yet ensuring the factual correctness of generated content remains challenging. Existing methods that provide statistical guarantees on factuality typically rely on external verifiers or generation-time confidence signals, which introduce auxiliary dependencies or often fail for confident but incorrect outputs. We argue that reliable factuality control can instead be achieved through introspective signals derived from the model itself. We introduce IntroConformal, a training-free Conformal Risk Control (CRC) framework that provides finite-sample, distribution-free factuality guarantees. We first instantiate it with layer-wise semantic stability, a conformity score derived from hidden-state representations, and then propose verification probability, a stronger score capturing the model's self-administered judgment on claim factuality. Across multiple LVLM architectures, IntroConformal satisfies the conformal risk guarantee while substantially reducing abstention and achieving competitive or superior claim-level discrimination relative to external verifier-based baselines.

## 2. 论文提出的方法论

**核心思想**：提出 IntroConformal——一个无训练的共形风险控制框架，通过模型自身提取内省信号，对响应级非事实风险提供有限样本、无分布假设的统计保证。

**流程总览：**
1. 将 LVLM 响应分解为原子声明（atomic claims）
2. 提取每个声明的内省一致分（所选分数）
3. 用校准集根据目标风险α选择最优阈值（LTT + Hoeffding UCB）
4. 保留分数≥阈值的声明，过滤低于阈值的声明

**两种一致分：**

**（a）逐层语义稳定性 S_sem**
- 来源：隐藏状态表征
- 对声明中的每个 token t，计算中间层集合 M（最终层之前的8层）的平均表示和最终层集合 T（最后4层）的平均表示
- 对两个平均表示进行余弦相似度计算（见Eq. 2-3）。
- 直觉：非事实生成伴随中后期层之间的语义漂移，内部表征不稳定；分数越高表示语义越稳定、越有事实性依据

**（b）验证概率 S_prob**
- 来源：同一 LVLM 对声明事实性的二值自我判断
- 提示："Based on the image, is the following statement true? Answer with Yes or No. Statement: c_i"
- 提取第一位置 Yes 和 No token 的预测概率，归一化为 Yes 概率占比（见Eq. 4）
- 与 CoVe 的关键区别：不采样离散答案、无额外解码步骤，直接从一次前向传播中提取 logits

- 定义且满足非事实风险纳管要求（Eq. 1），将平均删除内容的非事实率抑制在用户给定α以下。

## 6. 论文的主要结论与发现

1. **内省信号优于外部验证器与置信度信号**：S_prob 在所有任务和模型上均实现最强的事实/非事实区分能力。
   - 在LLaVA-1.5/MSCOCO上由CLIP的+0.0196和T_prob的+0.0523提升至+0.2014。
   - AUROC最高达到0.819（与S_prob+0.2014同组），较CLIP的0.631有大幅改善。

2. **外部验证器与置信度信号会失效或逆转**：在文档理解任务中，LLaVA-1.5的T_prob相对事实表现为反向差距（−0.0182、AUROC 0.493）；在 Llama-3.2-Vision/MSCOCO条件下，S_sem 同样有转置作用（−0.0003，AUROC 0.488），生成置信度或隐藏状态稳定性无法在所有架构上始终保持可靠。

3. **IntroConformal 满足共形风险边界并有较低的弃权率**：各实验组的经验风险均在α'=0.170的保证边界之下；S_prob较之CONFLVLM体系大幅降低弃权率（例如，MSCOCO/LLaVA-1.5条件下从57%降至25%）并提升了F1（0.504升至0.581）。

4. **共形风险随目标风险与校准量变化保持稳定**：α在0.05到0.40之间均有效；校准样本约200到400时具有稳定的标定效率。

5. **与解码方法相比更有效**：IntroConformal的声明过滤效率达97.4%，响应准确率达91%，优于Woodpecker、VCD、ICD、CoVe及CONFLVLM基线。

6. **对对称性标注噪声具有鲁棒性**：当校准数据受到15%的对称性噪声干扰后，经验风险反而降至0.001以下，同时弃权率上升——共形风险控制不受影响。

7. **结论**：模型自身的内部信号在非事实生成中提供了可靠的预测指标，模型内部各一致分与CRC机制的结合为高风险LVLM部署提供了一条无需外部依赖的原理性道路。


## 7. 优点

**方法层面：**
- 提出"内省信号 + 共形风险控制"的新组合，将机制可解释性内部分析结果转化为可验证的统计保证，跨界任务设计具有创新性。
- 填补了诊断工具和统计保证之间的空白——先有研究虽观察到来层的语义漂移能识别事实性缺陷，但没有提出与无分布假设保证衔接的完整应用路径。
- 无需训练，也无需外部依赖，S_prob 只需单一额外前向传播、处理内部表征可用性受限问题时仅需暴露输出logits即可。
- 将有序化、可嵌套声明过滤结构与 LTT + Hoeffding UCB 建模并处理了部分非单调风险路径（其比例意义在于声明被过滤时，剩余声明依然保持事实边界不变）。
- 明确LTT标注里存在分歧（α在实际操作中已作为调整后α′对待），对保证级别做到了透明度表述。

**实验层面：**
- 覆盖基准多样（场景理解、细粒度分类、文档理解场景）。
- 综合指标齐全：既覆盖共形框架直接保证层面的响应级风险与弃权率，也给出了用于分析和对比的声明级 F1、精确率、TPR。
- 报告了Welch t检验、AUROC和标注一致性检验（ICC（类内相关系数）为0.85、Cohen κ为0.71）等多维度统计指标，并加入标签噪声稳健分析。


## 8. 不足与局限

**方法论局限（作者已承认）：**
- S_sem 需要白盒访问模型内部激活，无法用于不公开隐藏状态的模型；S_prob 需要单位置 logits 输出，对不暴露 logits 的 API 也不适用。
- 两者均需要对每个声明额外执行一次前向传播，推理成本的增加是需要实际考虑的限制。
- 统计保证是概率性的（≥1−δ），高风险部署仍需人工监督。
- 保证定义基于校准标签而非人类真实标签；系统性标注偏差（非对称性噪声）可能会选择过于宽松的阈值，论文未充分测试。

**实验与实践局限：**
- 标注噪声测试仅覆盖单个模型和单一数据集。
- 仅少数模型被应用于文档理解分析场景（仅LLaVA-1.5与Phi），未覆盖五类模型全谱系配置。
- 层选择消融实验在Phi-3.5-Vision文档理解中目标场景出现了AUROC显著差距（0.628 vs 0.530），现有技术说明虽提到限制性，但尚未做更深入探讨。
- 假设固定模型与互换性前提——微调、RLHF更新或版本化API检查点更换均需重新校准，对自适应在线场景的适用性有限。
- 当出现对抗性构造图像或提示时，S_prob 容易受到 Yes/No logits 被恶意偏移的风险，目前尚未对此展开针对性的鲁棒性测试。
- 需要人工标注的声明（如“温馨氛围”类的价值/情绪性描述）在自动分解和标记时可能存在不一致风险。
