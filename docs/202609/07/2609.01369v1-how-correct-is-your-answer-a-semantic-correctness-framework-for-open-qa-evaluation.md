## 摘要
开放型问答的可靠评估仍然是衡量现代大语言模型答案正确性的瓶颈。与多项选择任务不同，自由形式的答案可能以多种表面形式呈现正确性，也可能以不同质的方式失败，包括不完整、矛盾、过度生成以及认可虚假前提。现有的基于判断和基于相似度的指标往往混淆了这些区分。我们通过三项可复用的贡献来弥补这一空白。首先，我们引入了一个语义正确性分类体系，将开放型答案划分为八个有序类别，将冗长但正确的答案与被幻觉内容污染的答案区分开来。其次，我们发布了CAP-Correctness，一个涵盖广泛使用的问答数据集的8.8k示例基准，以及CAP-Statements，一个用于将问答对转换为陈述句以进行自然语言推理（NLI）训练和基于陈述评估的11k示例数据集。第三，我们提出了CAP（上下文感知精确度），一种基于引用的指标，使用双向NLI对问题条件化陈述进行评分。在测试指标是否尊重分类体系预期顺序的单调性协议下，CAP优于现有基线。

## Abstract
Reliable evaluation of open-ended question answering remains a bottleneck for measuring answer correctness of modern LLMs. Unlike multiple-choice tasks, free-form answers may be correct in many surface forms and may fail in qualitatively different ways, including incompleteness, contradiction, overgeneration, and endorsement of false premises. Existing judgment-based and similarity-based metrics often collapse these distinctions. We address this gap with three reusable contributions. First, we introduce a semantic correctness taxonomy that assigns open-ended answers to eight ordered classes, separating verbose-but-correct answers from those contaminated by hallucinated content. Second, we release CAP-Correctness, an 8.8k-example benchmark spanning widely used QA datasets, and CAP-Statements, an 11k-example dataset for converting question-answer pairs into declarative statements for natural language inference (NLI) training and statement-based evaluation. Third, we introduce CAP (Context-Aware Precision), a reference-based metric that scores question-conditioned statements using bidirectional NLI. Under a monotonicity protocol testing whether metrics respect the taxonomy's intended ordering, CAP outperforms established baselines.

## 1. 论文的核心问题与整体含义（研究动机和背景）

开放式问答（Open QA）评估是衡量现代 LLM 答案正确性的关键瓶颈：

- **问题根源**：与多选题不同，开放生成的自由文本答案存在多种语义等价形态，且在失败时有质的差异，可能表现为 **不完整（partial）、不忠实（contradictory）、添加幻觉内容（overinclusive-invalid）或认可虚假前提**。现有评估手段往往将这些不同的失败模式混淆。
- **现有方法的缺陷**：
  - 基于精确匹配或词法重叠的指标（如 EM、BLEU 等）无法识别语义等价的正确改写，且会将表面相似但错误的答案判为正确。
  - LLM-as-a-judge 方法成本高、受提示词影响大、存在位置偏好与冗长度偏好，且可复现性差。
  - 单一的二元正确/错误标签过于粗糙，无法刻画答案出错的具体方式。
- **论文的整体目标**：构建一个可复用的、细粒度的、诊断性的开放问答评估框架。该框架以三类资源支撑，并最终落脚于一个新的语义评测指标 CAP。相关工作领域还涉及医学领域的实际评估（如 ClinIQLink、AraHealthQA 中现有自动指标的失败案例印证了这一需求）。

## 2. 论文提出的方法论

### 2.1 核心思想

将评估问题从「二元是否正确」转化为**「预测答案与参考答案在语义上的关系类别及其程度」**，通过一个**有序分类体系**与严格的单调性约束来诊断指标的精度。

### 2.2 八类语义正确性分类法（Taxonomy）

回答质量从高到低的顺序如下：

```
exact ≈ equivalent ≈ alternative-correct 
≥ overinclusive_valid > partial 
> overinclusive_invalid > invalid ≥ contradictory
```

各类别定义简述（与文末错误分析隐含的机制一致）：

- **exact**：与参考答案完全一致；
- **equivalent**：语义等价、措辞不同；
- **alternative-correct**：不同的但同样正确的答案（如问欧洲三个城市，答案不同但均正确）；
- **partial**：只提供了所需的部分信息（如要求三个城市只回答了两个）；
- **overinclusive-valid**：正确信息 **附加有效且相关的额外内容**；
- **overinclusive-invalid**：正确信息 **附加了错误的、无根据的幻觉内容**；
- **invalid**：语义错误的答案；
- **contradictory**：与参考答案或问题前提直接矛盾的答案。

其中 `overinclusive_valid > partial` 的排序决定了评测协议对有效冗长回答的偏好；`overinclusive_valid > overinclusive_invalid` 则要求包含幻觉内容的「部分正确」答案受到更重惩罚。这些排序对应了一条质量递减的预期曲线，即 **单调性（monotonicity）目标**。

### 2.3 CAP（Context-Aware Precision，上下文感知精确度）

这是论文提出的基于引用的参考型语义正确性指标，全流程如下：

1. **语句生成/改造**：用微调后的 mT5-small 模型将每个 QA 对（问题+答案）改写为**单一陈述句**：  
   \( s_g = s(q, g) \)，\( s_p = s(q, p) \)。
2. **方向性 NLI 打分**：使用 NLI 分类器（如 `cross-encoder/nli-deberta-v3-large`）计算两个单向推断分数：
   \[
   D(s_a \to s_b) = P_{entailment}(s_a \to s_b) + \lambda \cdot P_{neutral}(s_a \to s_b)
   \]
   其中 \(\lambda = 0.30\)。
3. **双向合并**：
   \[
   {\rm CAP}(s_g, s_p) = \alpha \, D(s_g \to s_p) + (1-\alpha)\, D(s_p \to s_g)
   \]
   其中 \(\alpha = 0.85\)（更侧重于从黄金答案蕴含预测答案的方向，即“正确内容的覆盖率”）。
4. **有界性**：由于 NLI 概率有界，CAP ∈ [0,1]。

### 2.4 评估协议：单调性 + 指标

为在指标间进行系统比较，论文定义了多种指标：Spearman ρ、Kendall τ、Pairwise Ranking Accuracy（成对排序准确率）以及**单调性违反计数（monotonicity violations）** 和困难相邻类别对准确率。

## 6. 论文的主要结论与发现

- **词法与嵌入指标基本失效**：在成对排序精度上接近随机基线（0.5），说明表面与语义重叠并不是可索引八级分类次序的有效信号。
- **COMET 更好但远不够**：COMET（最强基线）在 pairwise Acc 只达到 61.10（仍接近随机），在 25 对类别上违反 9 对。
- **CAP 显著提升排序对齐**：CAP 在 Spearman ρ 达到 60.37（对应 95% CI 58.56–62.11），比 COMET 翻倍，Kendall τ 达 48.83，Pairwise Acc 达 77.70；CAP 单调性违反数降为 4/25，而 BLEU/ROUGE/METEOR 违反 11—14/25。
- **失败模式集中且可解释**：CAP 的残余逆转集中在：
  - `alternative-correct` 得分偏低，因为有效替换答案不一定与参考互相蕴含，且受 NLI 世界知识所限；
  - `partial` 偏高而 `overinclusive-valid` 偏低，源于非对称加权（α=0.85）下的结构性产物。
- **对 LLM 生成的答案颇具泛化性**：在真实 LLM 自由回答的三组实验中，CAP 基本维持了类别排序顺序，其失败模式与合成数据集上一致。
- 提出的分类体系能够区分“含冗长但正确表达”的答案，“含幻觉内容的正确答案”与“有效扩展”，优于现有二维正确性+忠实性简化。

## 7. 优点

- **理论化评估框架**：用有序分类体系 + 单调性标准替代二元判断，为开放语义正确性衡量提供了具体、可复查的标准。
- **高质量资源**：发布两个新数据集（8.8k 类别标注集 + 11k 陈述生成集），均可作为后续社区统一的训练/评价基底。
- **指标与评估协议解耦**：CAP 自身的分类器可以推广到任何其他的语义评估指标使用该单调性协议做校准与比较，从而让数据集本身成为通用的“共享基台”。
- **完整自我诊断**：作者主动暴露并分析了 CAP 的结构性弱点（如 `partial/OV` 逆转、语义改造误差在长上下文场景的传播），较客观地拥抱了 NLI 类基础模型的局限。
- **实用性与可复现性**：基于已有的 DeBERTa NLI 与微调 mT5-small，且参数已披露（α、λ、批次、学习率），便于社区复现；比对成本低于 GPT-4-as-judge。
- 使用 bootstrap 置信区间的报告增加了结论可信度，并对标签来源（合成 vs 人工）的稳定性做了双重验证。

## 8. 不足与局限

- **NLI 的结构偏置**：基于全句双向蕴含 NLI 不能有效区分“部分信息”和“正确信息 + 有效冗余”，造成 partial 被抬升、overinclusive-valid 被压低；而 alternative-correct 需要很强世界知识与预训练覆盖才能识别。拆解到原子事实层面（如 FActScore）是未来的方向。
- **语言与领域局限**：主要限于英文教育类选择题改写来源数据（OpenBookQA、ARC、MMLU）；未涉及中文、多语种（虽初步评估过 mDeBERTa/XLM-RoBERTa）或代码/非英文问答。
- **数据质量风险**：
  - 8,827 条只有 1,638 条经人工验证，其余基于闭源 LLM 生成的标签；且人工标签是单标注员，没有估计 inter-annotator agreement；
  - 合成标签依赖具体 prompt 模板，可能带来隐蔽的类别分布或表达模式偏移。
- **语句生成瓶颈**：mT5-small 在长上下文类问题上的错误率 32.9%，语义改变 9.6%，使下游 CAP 在这个子集上可靠性降低；模型规模小会导致对整个框架误差的向上传导。
- **资源可负担性**：每一条评测需两次 NLI 计算+一次句子生成，比 BLEU/ROUGE/BERTScore 贵不少，对超大语料评测可能受限。
- **类别粒度粗化**：每条只标一个标签，无法处理同一个答案中“部分正确+额外错误”混合的情况，实际答案可能同时具有多个维度的偏差。
- **缺省生态对比**：未与主流的 LLM-judge 类评估器（如 GPT-4-as-judge）做直接的成本/性能/偏差对比，使得“CAP 有实际替代价值”这一结论在应用层面留有余地。
