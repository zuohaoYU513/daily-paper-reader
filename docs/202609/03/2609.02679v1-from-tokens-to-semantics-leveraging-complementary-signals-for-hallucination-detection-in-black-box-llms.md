## 摘要
当大语言模型支持面向公众或高风险工作流程时，漏检的虚构内容可能伤害用户和机构，而误报则会消耗有限的人工审核能力。在没有可信上下文或参考文档可用的情况下，我们研究了通过黑盒模型API可获取的两种信号：语义熵（衡量采样响应含义之间的分歧程度）以及从令牌对数概率导出的不确定性。它们的失效模式可能是互补的：当响应形成一个语义簇时，语义熵变得无信息量，而令牌不确定性可能遗漏始终自信的错误。我们通过我们的TopK方法聚合跨采样响应的令牌级信号，扩展了基于令牌的不确定性检测；评估了混合方法CoCoA（结合目标响应不确定性与语义不相似性）；并提出和研究了两种监督方法：Gated（将单簇案例路由到聚合令牌特征分类器）和Stacked（从语义不确定性和更广泛的令牌特征中联合学习）。我们使用四个语言模型评估了七个基准，包括五个公共基准（四个文本数据集和多模态手写支票提取）以及两个构建基准（财务摘要和长文本问答）。在我们跨模型和数据集的评估中，Stacked在近半数情况下表现最佳，而TopK和CoCoA在没有监督训练标签的情况下仍具竞争力，尽管它们的阈值需要仔细校准。没有一种方法在所有情况下都最强。因此，我们评估了在1%至15%假阳性率预算下的性能，考察其对生成和校准选择的敏感性，并检查跨数据集特征的变化。

## Abstract
When LLMs support public-facing or high-stakes workflows, missed fabrications can harm users and institutions, while false alarms consume limited human-review capacity. When no trusted context or reference document is available, we study two signals accessible through black-box model APIs: semantic entropy, which measures disagreement among sampled response meanings, and uncertainty derived from token log-probabilities. Their failure modes can be complementary: semantic entropy becomes uninformative when responses form one semantic cluster, while token uncertainty can miss consistently confident errors. We extend token-based uncertainty detection by aggregating token-level signals across sampled responses through our TopK method, evaluate the hybrid CoCoA method, which combines target-response uncertainty with semantic dissimilarity, and propose and study two supervised methods: Gated, which routes single-cluster cases to an aggregated-token-feature classifier, and Stacked, which learns jointly from semantic uncertainty and broader token features. We evaluate seven benchmarks, including five public benchmarks (four text datasets and multimodal handwritten-cheque extraction) and two constructed benchmarks (Financial Summaries and Long-Text QA), using four language models. In our evaluation across models and datasets, Stacked gave the best performance in nearly half of the cases, while TopK and CoCoA remain competitive without supervised training labels, although their thresholds require careful calibration. No method is universally strongest. We therefore evaluate performance at false-positive-rate budgets from 1% to 15%, assess their sensitivity to generation and calibration choices, and examine variation across dataset characteristics.

# 论文总结：从令牌到语义——利用互补信号在黑盒大语言模型中进行幻觉检测

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）越来越多地用于受监管机构及面向公众的高风险信息工作流。在这些场景中，模型生成的**虚构内容（幻觉）**若被漏检，可能误导下游用户与评审人员；而误报则会消耗有限的人工审核资源。
- **核心问题**：在**无参考文档、无可信上下文、也无模型内部状态（白盒）访问**的条件下，如何仅利用黑盒 API 可观测的信号来可靠地检测幻觉？
- **关键研究信号**：
  - **语义熵（Semantic Entropy, SE）**：通过对同一提示词采样 N 个响应并按语义聚类，衡量响应含义之间的分歧程度。
  - **令牌级不确定性（Token-level uncertainty）**：基于生成令牌的对数概率（token log-probabilities）衡量模型对单个输出内容的置信度。
- **核心观察**：两类信号的**失效模式互补**——
  - 语义熵在响应全部聚为**单一语义簇**时归零，即使该簇内容错误，也表现为零不确定性；
  - 令牌不确定性则可能**漏掉那些一致但自信的错误**（即模型每次都自信地生成同类错误内容）。
- **研究意义**：通过在黑盒条件下系统性结合互补的语义信号与令牌信号，为幻觉检测提供了条件性方法选择和校准指导，尤其适用于金融等高风险应用场景。

## 2. 方法论：核心思想与技术细节

### 2.1 整体框架

论文在**同一组 N 个采样响应**的基础上，同时提取语义级与令牌级信号，并提出三类方法。

### 2.2 语义不确定性度量（基线）

基于 N 个响应聚类到 K 个语义类别后的经验分布计算：

```
SE(x) = - Σ_k p̂(C_k) log p̂(C_k), 其中 p̂(C_k) = |C_k|/N
```

文中评估了标准 SE、SE UEigV（有限样本校正）、SE Hybrid（Good–Turing + UEigV 取大）、SE Von Neumann（基于响应相似性图的谱熵）、Spectral Epistemic 等多种变体。

### 2.3 TopK（无监督方法）

- 对每个响应取其**平均 top-k 熵** H_i^(k)，以及**平均被选令牌对数概率** ℓ̄_i；
- 将两者组合为跨响应的聚合分数：

```
U_TopK(x) = (1/N) Σ_i H_i^(k) + Var_{i=1...N}[ℓ̄_i]
```

- 更高值表明更大的不确定性。仅返回一个候选令牌（k=1）时，H_i^(1)=0，分数只保留跨响应置信度方差项。

### 2.4 CoCoA（现有混合方法，作为对比）

```
U_CoCoA(y*|x) = u(y*|x) × (1/N) Σ_i [1 - s(y*, y_i)]
```

其中 u 为目标响应的序列级不确定性（CoCoA SP 用原始序列负对数似然；CoCoA PPL 用长度归一化版本），s 为响应嵌入的余弦相似度。无监督，但需阈值校准。

### 2.5 Gated cascade（监督方法）

- 使用语义簇数 K 做路由：
  - 当 **K ≥ 2** 时，直接返回语义熵分数（如 Hybrid SE 或 Von Neumann 熵）；
  - 当 **K = 1** 时，标准 SE 恒为零，此时改用**在聚合令牌特征上训练的 L2 正则化逻辑回归分类器**。

### 2.6 Stacked classifier（监督方法）

- 不依赖路由规则，而是将**语义特征块 + 语义簇数 K + 聚合令牌特征向量**拼接；
- 经标准化、PCA（最多 15 个主成分）降维后，送入 L2 正则化逻辑回归分类器；
- 栈式让两类信号参与**每个查询**的预测，而非仅在单一簇时切换。

### 2.7 令牌特征工程

按四个维度提取特征：令牌置信度、位置置信度动态、跨响应聚合统计、语义多样性度量。骨干模型为 text-embedding-3-large 嵌入 + 贪心聚类。

- **部分数据集样本过小**：Long-Text QA 仅有 30 个问句集，置信区间宽泛，统计效力有限；
- **置信区间重叠**：在每一个数据集上，领先方法的 95% 置信区间都覆盖至少一个竞争者，无法在单一基准上确证某种方法的统计显著优势；
- **依赖 API 暴露的 token 对数概率**：如果 API 不返回 top-k 候选（如 GPT-5.4 仅给一个候选），部分令牌级信号会退化；
- **无法覆盖"高语义一致 + 高令牌置信"的失败场景**：当模型自信地编造语义一致的内容时，所有方法的检测能力均大幅下降；
- **跨模型超参数复用**：跨模型比较时 τ 与 C 不做重新调优，可能对不同模型的性能估计造成一定偏差；
- **自建基准未公开释放**：Financial Summaries 与 Long-Text QA 虽提供构造细节，但未作为开放数据集发布，外部直接复现受制约。
