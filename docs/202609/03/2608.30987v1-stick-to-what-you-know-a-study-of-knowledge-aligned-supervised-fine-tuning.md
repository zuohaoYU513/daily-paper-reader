## 摘要
监督微调（SFT）训练基础语言模型以模仿目标回答，而这些目标可能涉及基础模型尚未稳健内化的知识。我们将其视为幻觉的一个来源，并将一组缓解方法框架化为“知识对齐的监督微调”：即约束SFT训练目标以符合基础模型的参数化知识。在统一设置下，我们比较了现有的基于生成和基于估计的知识对齐方法，并引入了两种新变体：证据重写（Evidence Rewrite），利用外部证据验证基础模型生成内容；以及回忆重写（Recall Rewrite），仅保留基础模型能够一致回忆出的陈述。在Qwen 3 4B和OLMo 3 7B上的实验表明，知识对齐的监督微调可以减少WildHalu和Biography上的事实性幻觉，同时基本保持通用能力。回忆重写在事实性方面取得了最大的提升，并改善了UnknownBench上的拒绝行为。这证实了超出基础模型知识范围的SFT目标会诱发幻觉行为。

## Abstract
Supervised fine-tuning (SFT) trains a base language model to imitate target responses, and these targets may require knowledge the base model has not robustly internalized. We study this as a source of hallucinations and frame a group of mitigation methods as \emph{knowledge-aligned SFT}: constraining SFT training targets to the base model's parametric knowledge. Under a unified setup, we compare existing generation-based and estimation-based knowledge-alignment methods and introduce two new variants: Evidence Rewrite, which verifies base-model generations using external evidence, and Recall Rewrite, which retains claims only when they can be consistently recalled by the base model. Experiments with Qwen 3 4B and OLMo 3 7B show that knowledge-aligned SFT can reduce factual hallucinations on WildHalu and Biography while largely preserving general capabilities. Recall Rewrite yields the strongest factuality gains and improves refusal behavior on UnknownBench. It thereby confirms that SFT targets beyond the base model's knowledge drive hallucination behavior.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：大规模语言模型（LLM）在监督微调（Supervised Fine-Tuning, SFT）后常会生成流畅但含虚假或未经证实内容的回答，即“事实性幻觉”（factual hallucination）。该论文将幻觉的根源追溯到 SFT 训练目标要求模型输出的知识超出了其**参数化知识**（parametric knowledge）——即基础模型在预训练阶段已内化的知识。
- **核心假设**：如果 SFT 目标包含基础模型并未稳健掌握的事实、程序或结构知识，模型会被“逼迫”在不确定性下模仿出看似合理的答案，从而助长猜测而非拒答的倾向，最终扩展了“幻觉区”（hallucination zone）。
- **研究定位**：本文不试图通过 SFT 注入新知识（后续检索增强或继续预训练）来解决幻觉，而是主张将训练目标与模型已有知识对齐，即**知识对齐的监督微调（Knowledge-Aligned SFT）**。
- **整体含义**：论文提供了一套统一框架来比较和归纳幻觉缓解方法，主张“何种知识对齐策略被采用”对最终事实性的改善有决定性影响，并引入两种新的数据改写方案以实际落地该思路。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 统一框架

- 将一条训练响应 R 拆分为原子化“知识声明”（claim），即真实世界事实、程序性或结构性内容，且不包含已在提示 P 中明确提供的内容。
- 若所有声明的知识均属于基础模型 K(M_base)，则该训练样本为“知识对齐”。
- 知识对齐 SFT 的目标是从原始数据集 D 构建对齐数据 D\*，使所有响应的声明都在 K(M_base) 范围内，然后基于 D\* 做 SFT。
- 由于 K(M_base) 不可直接观测，用两种逼近策略实现：
  - **基于生成的对齐**：用基础模型自生成答案替代金标响应，假设自生成天然受限于其自身知识。
  - **基于估计的对齐**：逐条声明估计其是否在模型知识范围内，剔除“未知”声明（如用置信度或概率代理）。

### 2.2 两个现有基线方法

- **FLAME（基于生成）**：将问题分为“知识型”与“非知识型”两类。仅对知识型提示采样 M_base 生成响应替代金标。缺点是自生成仍会包含幻觉，且替换掉金标中的原有效知识。
- **UNIT_cut（基于估计）**：按声明条件概率（CCP）过滤低置信声明。缺点：token 级信号对措辞敏感，且显式声明外的隐式知识未被处理。

### 2.3 论文新增方法一：Evidence Rewrite

- 步骤：
  1. 判断提示是否为知识型；若是，从基础模型采样长格式响应；
  2. 用类似事实验证流水线（VeriScore 声明分解 → 维基百科证据检索 → FActScore 验证）判别每条声明是否得到外部证据支持；
  3. 移除不支持的声明，将剩余支持的声明交给改写模型（gpt-4o-mini）重新组织为流畅回答；
  4. 若所剩支持声明不足，改写器输出拒答模板。
- 特点：在 FLAME 基础上增加了外部事实核查环节，避免把模型自身幻觉当成可靠知识训练。
- 附带 **“头脑风暴”步骤**：针对初始短输出生成更长、更详细的版本，缓解因过滤导致的答案缩短问题。

### 2.4 论文新增方法二：Recall Rewrite（主要贡献）

- 核心思想：通过**封闭式问题生成 + 多次采样回答 + 蕴含判断**来探测“该声明是否可以被基础模型稳定回忆”。
- 具体流程：
  1. 首先将金标响应的声明区分为**知识依赖型**（可验证的事实/程序/结构知识）与**非知识依赖型**（上下文、主观或常识性内容）；
  2. 非知识依赖型声明直接保留；
  3. 对每条知识依赖型声明，由教师模型（gpt-5-mini）生成 J=5 个与上下文无关的探测问题；
  4. 对每个问题从基础模型采样 K=2 个答案（temperature=0.5）；
  5. 教师模型判定每个答案是“蕴含”“矛盾”还是“无关”原声明；
  6. 通过**一致可回忆判定式**（式 1）决策声明是否保留：
     - 至少 j_e 个问题具有蕴含性回答（每个问题中至少 k_e 条答案蕴含）；
     - 且至多 j_c 个问题具有矛盾性回答（每个问题中至少 k_c 条答案矛盾）。
  7. 改写器基于剩余声明（并排除未知声明及其暗示内容）重写为流畅响应；信息不足时输出拒答。

### 2.5 统一算法模板

- 论文用 Algorithm 1 概括所有方法共有的数据构建流程：GATE（该方法是否处理该提示）→ SOURCE（源响应来源）→ UNKNOWN（哪类声明判为“应移除”）。
- 不同方法仅在这三个钩子上不同，呈现高度模块化的比较框架。

## 6. 主要结论与发现

- **知识对齐的 SFT 确实能减少幻觉**：与标准 SFT 相比，除 FLAME 外所有知识对齐变体在 WildHalu 和 Bios 的 %Supp. 和 FActScore 均有提升。
- **知识边界的近似方式极大影响结果**：
  - FLAME（纯自生成）未能超越标准 SFT → 自生成不可靠；
  - 加入外部核查的 Evidence Rewrite 优于 FLAME；
  - Recall Rewrite 通过稳定回忆探测取得最强事实性提升，但代价是更高拒答率、更少支持声明 → 在“信息覆盖度—事实性”之间存在清晰权衡。
- **%Known 消融因果验证**：在保持提示、拒绝数量（非拒答 1,777 / 拒答 302）和训练设置不变的情况下，提高已知声明占比能有效提高 %Supp. 和 FActScore；100% 已知时最好，50% 次之，0% 最差。
- **拒答行为**：Recall Rewrite 在 UnknownBench 的三个子任务上大幅提升拒答召回率（R 最高可达 79.1%），但精确率偏低（更多过度拒答）；F1 在各子任务中均为最优。
- **通用能力基本保持**：OLMES 平均只比标准 SFT 低 0.9 分，处于 OASST1 模型差异带宽（2.1 分）内。IFEval 差距完全源于 Recall Rewrite 对 30 个提示拒答（多为创意写作），对非拒答提示二者持平；GSM8K 差异为普通推理失误，未见拒答证据。
- **与多阶段后训练的对比**：仅靠知识对齐数据做 SFT，WildHalu 上的事实性可与 OLMo 3 Instruct 的官方 DPO/RLVR 检查点相当甚至更优；是否与 RL 类目标叠加仍有待验证。
- **不当拒答存在系统性盲点**：对代码类（31% 拒答是含代码的提示）、创意写作类和名人不完全了解的实体上，过度拒答显著。

## 7. 优点

- **统一框架、模块化比较**：首次将 FLAME、UNIT_cut 与两种新方法放入同一数据构造算法结构（Algorithm 1）内比较，清晰展示各方法实质差异是什么。

- **严谨的因果归因（%Known 消融）**：在控制训练配方不变的情况下，只改变已知声明占比，直接验证“SFT 目标超出模型知识确实诱发幻觉”的因果链条。
- **公开数据与代码**：开源 Recall Rewrite 的全套中间产物，可供后续工作直接复现或研究。
- **讨论深入、诚实**：明确区分“降低幻觉”与“降低信息覆盖”的不同含义，并通过 FActScore（拒答视为满分）与 #Supp. 的并列报告避免指标自欺。
- **详细定性分析**：附录通过示例展示正误情况（成功移除错误知识、拒答泛化、相干性丢失等），暴露方法真实优缺点。

## 8. 不足与局限

- **知识不可直接观测**：K(M_base) 是隐含量，任何基于行为/置信度/生成的估计都有误差；本框架对知识做二元分类（已知/未知），未建模模型内部的梯度式知识或措辞敏感性。
- **评测维度偏窄**：事实性评测聚焦于单一实体的长式生成；未覆盖多跳、多对话轮、聚合长文、结构化输出等场景；对“知识型提示”的判定本身也高度依赖模板与选定分类器。
- **实验规模有限**：仅使用 OASST1 英文首轮 3,468 条训练样本；与当前工业级、大规模指令数据的规模差距明显（Tülu 3 对比只表明“数据量大不一定更好”）。
- **外部工具依赖与偏差风险**：
  - Evidence Rewrite 依赖维基百科证据，维基未覆盖的真实知识容易被误判为不支持；WildHalu 一半实体无维基词条，事实验证难度高；
  - 自动声明验证有系统误差；评估用 gpt 系列做分解/判断可能引入不确定性与主观性偏移；
- **过度拒答问题**：Recall Rewrite 更强的拒答倾向导致许多本可正确回答或半正确回答的问题被拒（如代码或创意写作）；在不同应用场景（教育、客服、代码协助）中的实际弊利需要重新权衡。
- **成本与可扩展性**：Recall Rewrite 需要多步 API 调用与大模型参与；当前主要适合高精度诊断与小规模数据处理，尚不是可直接扩展至大规模指令管线的成熟方案。
- **教师模型效应未充分解耦**：不同教师模型（gpt-4o-mini 与 gpt-5-mini）在声明分解、问题生成、重写风格及拒答模板上存在差异，其对最终结果的贡献难以与“知识对齐本身”剥离。
- **与偏好优化/强化学习的叠加效果未知**：论文只表明单独 SFT 阶段知识对齐有效，但没有探索知识对齐数据与 DPO、RLVR 等阶段的组合增益。
