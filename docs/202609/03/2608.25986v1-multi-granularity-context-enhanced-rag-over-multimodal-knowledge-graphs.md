## 摘要
检索增强生成（RAG）被广泛用于缓解大语言模型（LLM）和多模态大语言模型（MLLM）中的幻觉问题。特别是，基于知识图谱（KG）的RAG利用结构化知识为（M）LLM提供高质量的外部信息。在这些工作的基础上，近期研究探索了将多模态知识图谱（MMKG）作为GraphRAG的知识库。这使得GraphRAG能够跨多种模态整合知识，从而进一步提升其性能。然而，现有的基于MMKG的RAG方法通常遵循一种通用流程，其中不同模态在很大程度上被独立处理后再进行融合。因此，在视觉信息提取及后续的多模态知识融合过程中，文本上下文仅被有限地利用。这导致了图像与文本之间的语义鸿沟，限制了多模态GraphRAG的性能。为解决这一问题，我们提出了一种构建上下文增强多模态知识图谱（CEMMKG）的新框架，以更好地支持多模态GraphRAG。所提出的CEMMKG在局部和全局范围内为每张图像补充了互补的文本上下文。局部上下文超越了周围文本，通过纳入与图像语义相关的句子来扩展信息，而全局上下文则提供整个段落的摘要。我们进一步引入了局部上下文的多粒度设计，使其能够在不同细节层次上捕获语义相关信息。在选定的以视觉为中心的数据集上进行的大量实验验证了CEMMKG在利用上下文信息提升基于MMKG的RAG性能方面的有效性。此外，其在不同基于MMKG的RAG方法上的有效性证明了其广泛的适用性。

## Abstract
Retrieval-augmented generation (RAG) is widely used to mitigate hallucination issues in large language models (LLMs) and multimodal large language models (MLLMs). In particular, knowledge graph (KG)-based RAG leverages structured knowledge to provide (M)LLMs with high-quality external information. Building on these works, recent studies have explored multimodal knowledge graphs (MMKGs) as knowledge bases for GraphRAG. This enables Graph RAG to integrate knowledge across multiple modalities, thereby further enhancing its performance. However, existing MMKG-based RAG methods generally follow a common pipeline in which different modalities are largely processed independently before being fusion. As a result, textual context is only used to a limited extent during visual information extraction and subsequent multimodal knowledge fusion. This brings a semantic gap between images and text which limits the multimodal GraphRAG performance. To address this issue, we propose a novel framework for constructing a Context-Enhanced MMKG (CEMMKG) to better support multimodal GraphRAG. The proposed CEMMKG enriches each image with complementary textual context at both local and global scopes. Local context goes beyond the surrounding text by incorporating sentences that are semantically related to the image, while global context provides a summary of the entire passage. We further introduce a multi-granularity design for the local context, allowing it to capture semantically relevant information at different levels of detail. Extensive experiments on the selected vision-centric dataset validate that CEMMKG is effective in leveraging contextual information to improve MMKG-based RAG performance. Moreover, its effectiveness across different MMKG-based RAG methods demonstrates its broad applicability.

- 大规模语言模型（LLM）与多模态大语言模型（MLLM）虽能力强大，但易产生幻觉，检索增强生成（RAG）是缓解该问题的主流方案。

  - 视觉信息提取时仅依赖图像周边的少量文本（相邻文本块）；

### 二、方法论：CEMMKG 框架

#### 2.1 核心思想

构建“上下文增强的多模态知识图谱”（Context-Enhanced MMKG，简称 CEMMKG），为每个视觉元素（图像、表格等）设计**局部上下文 + 全局上下文**两种互补的文本上下文，并在**图像到图（Image2Graph）构建**与**跨模态图融合**两个阶段分别注入，以提高视觉知识提取质量和图文实体对齐精度。

#### 2.2 多粒度局部上下文（Local Context）

局部上下文由两部分组成，其中一部分是继承现有方法的基线组件，另三部分为核心创新：

| 组件 | 说明 |
|---|---|
| **邻接文本（surrounding）** | 图像在文档中位置前后紧邻的文本块，为后续融合保留的既有基线上下文 |
| **引用句子（reference sentence）** | 通过图像 ID（如“Figure 3”）找到所有文档中显式提及该图标的句子，并附上其前后各一句——最精炼直接的上下文 |
| **引用段落（reference paragraph）** | 包含引用句子的完整段落——覆盖面广但信息密度低，可能引入噪声 |
| **引用段落摘要（reference paragraph summary）** | 用 LLM 对引用段落生成摘要，在覆盖面和密度之间取得平衡 |

其中三种基于“引用（reference）”的组件构成不同粒度下的**互斥可选配置**，需要用实验确定最优粒度。局部上下文由邻接文本与选定的引用级组件共同构成。

#### 2.3 全局上下文（Global Context）

- **摘要（Abstract）**：直接使用文档已有的原始摘要；
- **文档总结（Document Summary）**：在无摘要时用 LLM 对整个文本内容生成总结。
- 全局上下文属于文档级共享信息，为所有视觉元素提供宏观语义背景。

#### 2.4 上下文约束（防过载机制）

- 仅保留按文档顺序**靠前的若干个引用位置**（图像描述阶段最多 5 处，融合阶段最多 3 处）；
- 分别对局部引用上下文和全局上下文设置长度上限，防止相互挤占或过长导致“lost in the middle”问题。

#### 2.5 多阶段上下文利用（Multi-Stage Context Utilization）

- **阶段一：上下文增强的图像建图**：将完整上下文 $\tilde{C}_i = \left\{C_i^L,\ C^G\right\}$ 提供给 Image2Graph 模块，替换原有仅邻接文本的方式，引导 MLLM 在描述视觉内容时参考图像特定证据和文档整体语义。
- **阶段二：上下文引导的 MMKG 融合**：将局部上下文（不含全局上下文）作为额外证据注入融合模块，扩大视觉实体与文本实体对齐时的候选范围，提高跨模态对齐的准确性。

### 六、主要结论与发现

1. **最优配置为“引用句子 + 文档级全局上下文”**：在 MMGraphRAG 骨干上，严格准确率为 34.91%、软准确率 36.84%，远超 MMGraphRAG 原版的 23.58% / 24.17%。
2. **参考段落摘要配置次优**（31.13% / 32.82%），但优于原版；
3. **直接使用完整引用段落反而导致性能下降**（22.64% 软准确率 < 原版 24.17%），说明**更多上下文并不一定更好**：粒度过粗会引入不相关噪声。
4. 不同类型的视觉内容收益不同：
   - Figure 类题目：引用句子的软准确率从 6.25% 提升至 24.70%；
   - Chart 类题目：引用句子与基线持平；
   - Table 类题目：引用段落摘要最优（从 22.46% 提升至 26.46%）；
   - Misc（无显式视觉标签但可能隐含）类：软准确率从 34.15% 提升至 54.01%，说明增强的图融合也有助于文本侧问答。
5. **CEMMKG 可适用于不同 MMKG-RAG 骨架**：集成到 RAG-Anything 后，严格准确率从 28.89% 提升到 35.56%，软准确率从 36.18% 提升至 41.12%。

### 七、主要优点

- **问题定义清晰、系统性强**：将“文本上下文”从模糊概念明确划分为邻接、引用句、引用段、引用段摘要、摘要、全文总结，按粒度和位置两个维度进行系统消融。
- **方法轻量、不侵入**：不改变核心建图与融合网络结构，仅替换或增补输入上下文，兼容性强。
- **发现的重要反直觉结论**：不是加的上下文越多质量越高，而是要与目标视觉元素语义对齐、粒度适当，这为后续工作提供了有实际意义的指引。
- **解释性较强**：提供了局部与全局上下文、不同图文证据传播路径的清楚分析（即不同建图阶段利用不同层次信息）。
