## 摘要
自回归大型语言模型（LLM）在解码置信度较高的情况下仍会经常生成与事实不符的输出，这限制了它们在高风险工作流中的部署。当模型对错误断言过度自信时，现有的输出阶段不确定性指标可能会失效，而多样本验证流水线则会引入大量的内存和延迟开销。本研究评估了生成过程中的内部隐藏状态转换动态是否能在不进行辅助解码调用的情况下发出事实错误的信号。我们提出了预测的预测（PoP）机制，该机制通过在一次前向传播中融合跨深度层的中间隐藏表示来捕获层间转换不确定性。在使用自回归Transformer主干网络进行的TruthfulQA基准测试中，PoP在事实正确性分类任务上达到了75.5%的受试者工作特征曲线下面积（AUROC）。该机制在基础前向传播内运行，额外延迟低于1.2%，且无需额外的生成过程。数值结果来自作者验证的实验实现，并受限于下文所述的评价范围。

## Abstract
Autoregressive large language models (LLMs) routinely generate factually incorrect outputs with high decoding confidence, limiting their deployment in high-stakes workflows. Existing output-stage uncertainty metrics can fail when models are overconfident on false assertions, while multi-sample verification pipelines introduce substantial memory and latency overhead. This work evaluates whether internal hidden-state transition dynamics during generation can signal factual errors without auxiliary decoding calls. We introduce Prediction of Prediction (PoP), a mechanism that captures layer-transition uncertainty by fusing intermediate hidden representations across depth during a single forward pass. Evaluated on the TruthfulQA benchmark using autoregressive transformer backbones, PoP achieves an area under the receiver operating characteristic curve (AUROC) of 75.5% for factual-correctness classification. The mechanism operates within the base forward pass, adding less than 1.2% runtime latency and requiring zero additional generation passes. The numerical results are reported from the author-verified experimental implementation and are bounded by the evaluation scope described below.

## 二、论文提出的方法论

### 2.1 核心思想

PoP 的核心假设是：**幻觉信号不仅存在于某一层静态隐藏状态中，更体现在表示随层间传播的转换动态中**。浅层到深层的表示变化包含了从语法处理到语义承诺的转变过程，这一过程中的异常模式可以指示事实错误。

### 2.2 关键技术细节

PoP 的工作流程分为三个主要阶段：

**第一阶段：内部表示捕获**
- 在解码步骤 t，通过前向钩子（forward hooks）捕获各层归一化后的隐藏状态，构建隐藏状态矩阵 Ht = [ĥ_t^(1); ĥ_t^(2); ...; ĥ_t^(L)] ∈ R^(L×d)
- 使用 LayerNorm 消除跨层尺度差异，且不改变基座模型权重或 KV 缓存执行图。

**第二阶段：层间转换不确定性统计**
- 计算相邻层之间的**余弦距离**作为过渡散度：δ_t^(l) = 1 − cos(ĥ_t^(l), ĥ_t^(l−1))
- 聚合得到过渡向量 u_t = [δ_t^(2), δ_t^(3), ..., δ_t^(L)]，并通过可学习深度权重 w_l 计算轨迹散度统计量 D_t。
- 通过**跨层注意力**机制（投影到 Q/K/V 空间）对隐藏状态矩阵进行融合，得到融合状态 z_t。
- 计算**时间漂移** Δz_t = z_t − z_{t−1}，衡量跨解码步骤的表示变化。

**第三阶段：评分与校准**
- 将融合状态、过渡向量和时间漂移拼接为元表示 x_t = [z_t ∥ u_t ∥ Δz_t]
- 通过两层 MLP 输出步骤级幻觉概率 U_t
- 使用 Platt 缩放对序列级得分进行校准：S_PoP(Y) = σ(α·(1/T)ΣU_t + β)

### 2.3 算法流程（在线推理）

> 每个解码步骤执行一次生成器前向传播（带钩子）；捕获 H_t 并生成 y_t；计算过渡向量 u_t（复杂度 O(Ld)）；通过跨层融合计算 z_t（复杂度 O(L²d_k + Ld)）；拼接特征并计算 U_t；最终返回序列级校准得分。

**复杂度总结：** 临时激活内存 O(Ld)，每个 token 仅一次前向传播，零额外生成调用，评分头参数小于 140 万（d_k=64, d=4096 时）。

## 六、论文的主要结论与发现

1. **检测性能**：PoP 在 TruthfulQA 上达到 75.5% AUROC，在 HaluEval 上达到 74.6%，均优于所有单次前向传播基线，接近甚至超过需要多次采样或外部模型的深层方法。
2. **效率优势**：额外延迟仅约 0.3 ms/token（总延迟从 24.1 提升至 24.4 ms/token），VRAM 开销仅 18.4 MB，吞吐惩罚 1.2%——远低于语义熵（延迟 120.5 ms/token，4 倍以上吞吐惩罚）和 NLI 级联（额外 1740 MB VRAM）。
3. **校准改善**：Platt 校准将 ECE 从 0.142 降至 0.031，Brier 分数从 0.188 降至 0.124。
4. **有序层间转换是核心**：打乱层序导致 AUROC 降至 58.3%（下降 17.2 个百分点），证明层间有序转换信息至关重要；仅使用静态特征（AUROC 67.2%）或仅使用过渡特征（70.1%）均明显低于完整框架（75.5%）。
5. **跨模型/跨域迁移**：零样本迁移时 AUROC 损失不超过 4.3 个百分点，表现较为稳健。
6. **扰动鲁棒性**：在 5 种扰动下 AUROC 损失最多 2.4 个百分点，对表面风格变化不敏感。
7. **早期预警能力**：风险分数在错误实体出现后约 1.2 ± 0.4 个 token 内跨过 0.70 阈值，可平均阻止 18.4 个后续解码步骤。

## 八、不足与局限

1. **白盒访问限制**：PoP 需要访问中间隐藏状态，无法直接应用于只暴露文本或 token 概率的封闭 API，实用性受限。
2. **对 ICR Probe 对拍不完整**：论文明确指出 ICR Probe 是最接近的对比器，但正文未提供与其实现的直接实验对比数据，削弱了 novelty claim 的可验证性。
3. **实验覆盖范围有限**：
   - 仅限英语生成；跨语言性能未验证
   - 长文本/长文档生成、推理链可靠性未覆盖
   - TruthfulQA 中 817 个问题规模偏小
4. **基准时效性**：论文设定在 2026 年，但 TruthfulQA、HaluEval 等基准相对陈旧，缺乏更新的基准（如 SimpleQA、FreshQA 等）验证。
5. **鲁棒性验证有限**：
   - 扰动测试局限于 5 种语法/风格扰动
   - 未测试对抗性攻击、提示注入等恶意场景
   - 温度 0.7 扰动时 AUROC 降至 73.1%，说明在较高采样温度下性能仍有下降
6. **缺乏统计严谨性**：未报告多次运行的均值/方差/置信区间，未进行显著性检验。
7. **仅报告预测相关性，不证明因果性**：论文坦率承认没有进行激活打补丁（activation patching）或因果干预实验，无法确认层间转换是幻觉的因还是果。
8. **监督校准需求**：评分头和校准参数需要标注验证数据，在分布严重偏移时校准可能失效。
9. **早期预警的实践局限**：token 级结果依赖标注协议；部署时需进一步考虑假中断、重启成本、用户可见质量等问题。
