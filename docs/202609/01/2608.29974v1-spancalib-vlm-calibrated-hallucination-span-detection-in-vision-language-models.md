## 摘要
检测大型视觉-语言模型（LVLMs）中的幻觉需要准确的跨度定位和良好校准的置信度分数。微调后的生成式视觉语言模型在识别幻觉文本跨度方面表现出色，但存在过度自信和高推理延迟的问题。判别式序列标注器提供确定性的速度和优越的校准，但表现出保守的跨度召回率。我们提出SpanCalib-VLM，一个用于SHROOM-Visions共享任务的混合双系统，它结合了一个多模态序列标注器（由XLM-RoBERTa-Large与通过交叉注意力融合的SigLIP视觉编码器组成）以及我们微调的生成式视觉语言模型（Qwen3.5-4B-SHROOM-SFT）。通过联合校准融合策略，来自生成模型的候选跨度使用序列标注器的校准概率重新评分。在SHROOM-Visions英文评估集上，我们的集成方法实现了0.41的Pearson校准相关性和0.39的总体IoU，其中干净响应的IoU为0.91，总体检测准确率为70.7%。我们公开了我们的模型权重和代码。

## Abstract
Detecting hallucinations in Large Vision-Language Models (LVLMs) requires both accurate span localization and well-calibrated confidence scores. Fine-tuned generative VLMs excel at identifying hallucinated text spans but suffer from overconfidence and high inference latency. Discriminative sequence taggers offer deterministic speed and superior calibration but exhibit conservative span recall. We present SpanCalib-VLM, a hybrid dual-system for the SHROOM-Visions Shared Task that combines a multimodal sequence tagger, consisting of XLM-RoBERTa-Large fused with a SigLIP vision encoder via cross-attention, with our fine-tuned generative VLM (Qwen3.5-4B-SHROOM-SFT). Through a Union-Calibrated Fusion strategy, candidate spans from the generative model are re-scored with calibrated probabilities from the sequence tagger. On the SHROOM-Visions English evaluation split, our ensemble achieves a Pearson calibration correlation of 0.41 and an overall IoU of 0.39, with a clean-response IoU of 0.91} and overall detection accuracy of 70.7%. We make our model weights and code publicly available.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型视觉-语言模型（LVLMs，如 GPT-4V、Qwen-VL、MiniCPM-V）在视觉问答和多模态推理方面取得了显著进展，但**频繁产生视觉幻觉**——即生成与图像内容不符的文本，包括错误描述场景、凭空捏造物体或错误刻画属性。
- **核心挑战**：SHROOM-Visions 共享任务要求系统同时完成两项任务：
  1. **精确定位幻觉段落的字符级边界**（span localization）；
  2. **输出良好校准的连续概率分数**（confidence calibration），评估指标为 Pearson 相关系数。
- **现有两大范式的困境**：
  - **生成式 VLM 微调**：能输出结构化 span 标注，实现高 span IoU，但存在**过度自信**和**高推理延迟**（链式推理模式下单样本耗时可达 23 秒）；
  - **判别式序列标注**：单次前向传播即可完成推理，速度快且输出校准良好，但 span 边界**偏保守**（recall 偏低）。
- **研究意义**：本文旨在弥合上述两种范式的鸿沟，通过混合双系统结构同时获得高精度定位与良好校准，为幻觉检测提供一种兼顾速度与可靠性的新方案。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构（混合双系统）

系统由两个子系统与一个融合策略组成，核心思想是**让生成式模型负责"提案"（proposal），让判别式模型负责"校准"（calibration）**：

### 2.2 系统 1：多模态序列标注器（判别式）

- **文本编码器**：XLM-RoBERTa-Large（24 层，隐藏维度 dₕ = 1024）。输入格式为 `"Question: Tp \nResponse: Tr"`，最大 token 数 N = 512，得到文本隐状态 H_text ∈ R^{N×dₕ}。
- **视觉编码器与跨注意力融合**：
  - 使用 SigLIP-2（SigLIP base patch16-224）提取图像特征，得到 patch 嵌入 V ∈ R^{196×768}；
  - 通过线性投影映射到文本隐空间（V_proj ∈ R^{196×dₕ}）；
  - 通过**跨注意力**将视觉上下文融入语言表示，融合公式为：

  ```
  H_fused = LayerNorm(H_text + Softmax(QK^T / √dₕ) · U)
  ```

- **多头任务头**（每个 token 上并行三个头）：
  1. **Span 分类头**（Head_span）：2 层 MLP → sigmoid，预测二值幻觉概率 ŷᵢ ∈ [0,1]；
  2. **概率校准头**（Head_calib）：2 层 MLP → sigmoid，直接回归预测连续校准分数 p̂ᵢ ∈ [0,1]；
  3. **类别分类头**（Head_cat）：2 层 MLP → softmax，预测 5 类错误类型。
- **训练目标**（多任务联合损失）：

  ```
  L = L_BCE(ŷ, y) + λ₁·L_MSE(p̂, p) + λ₂·L_CE(ĉ, c)
  ```

  其中 λ₁ = 1.0，λ₂ = 0.5。MSE 项直接以人工标注者一致性比率 p 作为回归目标，监督 token 级置信度校准；辅助分类损失 L_CE 作为多任务正则化器。

### 2.3 系统 2：生成式 VLM（提案器）

- 通过监督微调（SFT）在 SHROOM-Visions 训练数据上微调 **Qwen3.5-4B**，输出结构化 JSON span；
- 输出中的候选 span S_VLM 被转换为二值字符掩码 M_VLM(k) ∈ {0, 1}。

### 2.4 Union-Calibrated Fusion（联合校准融合策略）

融合算法流程：

1. 从系统 2 提取候选 span 边界 S_VLM；
2. 通过子词偏移对齐（subtoken offset alignment），将系统 1 的 token 级概率映射为字符级概率数组 P_SC(k)；
3. 计算概率引导的集成分数：

  ```
  P_ens(k) = w₁ · P_SC(k) + w₂ · M_VLM(k)
  ```

  其中 **w₁ = 0.55，w₂ = 0.45**（在验证集上通过超参数网格搜索确定）。给系统 1 略高的权重是因为其校准基线更优（Pearson 0.369 vs 0.285），而系统 2 的二值掩码作为候选 span 的空间提案权重。

### 2.5 核心设计逻辑

- 生成式模型利用"深思熟虑"的推理优势提出高召回候选 span；
- 判别式模型用校准概率为这些候选"重新评分"，抑制生成模型的过度自信；
- 融合后的分数分布呈**双峰形态**（VLM 提案内字符得分高、外部得分低），因此对决策阈值不敏感。
