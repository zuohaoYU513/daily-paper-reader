## 摘要
KV缓存压缩通过驱逐上下文标记来减少LLM推理内存，但当被驱逐的标记包含承载答案的证据时，模型可能会产生幻觉，而不是认识到压缩后的上下文不足。我们从行为角度解决这一失败：据我们所知，这是首个将压缩感知弃权表述为学习问题的工作，其中模型学会在支持性证据在压缩中幸存时回答，在证据被移除时弃权。我们从压缩器生存掩码和紧密的答案承载跨度构建监督信号，当证据幸存时标记示例为“自信”，当证据被移除时标记为“弃权”。在约2.6K个MuSiQue两跳问答示例上训练的1010万参数LoRA适配器，在提示式截断下将基础模型的幻觉减少97%，同时在保留证据的示例上保持正确回答。与仅提示的弃权基线（在许多可回答的高保留示例上过度弃权）不同，训练后的适配器学习了一个条件策略。我们还在实际压缩缓存解码下评估了该方法，其中多压缩器训练在保留证据的示例上相对于未辅助基础模型产生了6-22倍的相对提升。受控删除实验表明，学习到的行为由证据内容驱动，而非仅由输入长度驱动。

## Abstract
KV-cache compression reduces LLM inference memory by evicting context tokens, but when the evicted tokens contain answer-bearing evidence, the model may hallucinate instead of recognizing that the compressed context is insufficient. We address this failure from a behavioral perspective: to our knowledge, this is the first work to formulate compression-aware abstention as a learning problem, in which a model learns to answer when supporting evidence survives compression and abstain when it does not. We construct supervision from compressor survival masks and tight answer-bearing spans, labeling examples as Confident when evidence survives and Abstain when it is removed. A 10.1M-parameter LoRA adapter trained on ~2.6K MuSiQue 2-hop QA examples reduces base-model hallucinations by 97% under prompt-style truncation while preserving correct answering on evidence-retaining examples. Unlike prompt-only abstention baselines, which over-abstain on many answerable high-retention examples, the trained adapter learns a conditional policy. We also evaluate the method under actual compressed-cache decoding, where multi-compressor training yields a 6-22x relative lift over the unaided base on evidence-retaining examples. Controlled-deletion experiments show that the learned behavior is driven by evidence content rather than input length alone.

# 论文详细总结：Compression-Aware Abstention（压缩感知的弃权）

## 一、核心问题与研究动机

- **背景问题**：KV 缓存压缩（KV-cache compression）通过驱逐被判定为"不重要"的上下文 token 来降低推理内存占用，其设计假设是被驱逐的 token 不携带答案相关信息。然而当驱逐规则恰好删除了对某个下游查询至关重要的**答案承载证据**（answer-bearing evidence）时，模型面对缺失关键证据的截断上下文，往往会**编造一个自信的错误答案**，而不是承认信息不足。
- **现有方案缺口**：此前的缓解方案属于"表征侧"（representation-side），例如将驱逐条目以低精度形式保留而不是完全丢弃；尚无工作从**行为侧**（behavioral side）训练模型学会"诚实弃权"。
- **核心主张**：本文首次将"压缩感知弃权"（compression-aware abstention）形式化为一个**学习问题**——模型应学会在支持性证据经压缩后仍然幸存时作答、在证据被移除时拒绝回答。这与训练感知压缩（如 KV-Distill，旨在保持未压缩模型的输出行为）是**互补**而非竞争的关系。

## 二、方法论

### 2.1 核心思想

训练数据由压缩器产生的**生存掩码**（survival mask）与**紧密答案跨度**（tight answer-bearing spans）构建监督信号：
- 当支撑答案的紧密证据跨度在压缩后存活，标签为 **CONFIDENT**（应作答）；
- 当支撑证据被移除，标签为 **ABSTAIN**（应弃权）；
- 中间不确定区间标记为 DROP（从训练中剔除）。

### 2.2 关键定义与公式

**压缩截断输入**：设上下文 token 化为 c ∈ V^nc，压缩器在保留率 r 下产生逐 token 生存掩码 m ∈ {0,1}^nc，压缩截断输入为保留 token 的拼接 c̃(m) = (c_i : m_i = 1)。

**证据存活分数**（式 1）：对支撑跨度 S_k 定义为

ρ(m, S_k) = Σ_{i∈S_k} m_i / |S_k|

即跨度内幸存 token 的比例。

**金标签**（式 2）：给定阈值 τ_low < τ_high，当 min_k ρ(m, S_k) ≥ τ_high 时标记 CONFIDENT；当 min_k ρ(m, S_k) < τ_low 时标记 ABSTAIN；落入 [τ_low, τ_high) 的示例被丢弃（DROP）。实验中取 τ_low = 0.3、τ_high = 0.8。

**学习目标**（式 3）：将每个 (c, q, a, m, S) 映射为目标字符串 t = a（CONFIDENT 时）或 t = t⊥（固定拒答语句，ABSTAIN 时），训练 LoRA 参数 θ 最小化

L(θ) = −Σ_{(m,q,t)∈D} log f_θ(t | c̃(m), q)

该损失可分解为 L_CONF + L_ABS，分别惩罚"证据幸存时弃权"和"证据缺失时作答"，从而逼出**双向条件策略**（回答与弃权均按证据内容调节）。

### 2.3 紧密跨度定位（Tight-span localization）

- 利用 MuSiQue 数据集中的 `question_decomposition` 字段，将每个单跳子答案的**逐字字符串**定位到支撑段落中，形成紧密跨度（中位数 3 个 token，99 分位 11 个 token；100% 定位成功）。
- **关键动机**：若采用整段支撑段落（约 100 token）作为跨度，ρ 会被平均化——在 r=0.50 时每个段落约保留一半 token，所有示例落入 DROP 区间，标签熵为 0（完全丧失信号）；而紧密跨度在 r=0.50 时标签熵达 0.95，保留了逐示例的区分度。

### 2.4 训练管线

- 压缩器（KVzip）产生掩码 m → 标签器按紧密跨度存活率计算 ρ 并分配标签 → 过滤 DROP 后构成训练集（约 2.6K 个实例，验证集 463 个，按示例 ID 不重叠分割）。
- LoRA 适配器：秩 16、α=32、dropout 0.05，仅适配四个注意力投影（q/k/v/o），不修改 MLP；参数量 1010 万，占 Qwen2.5-7B-Instruct 的 0.13%。
- 标签分布随保留率呈 U 形，因此在 r ≥ 0.20 时施加 30/70 少数类下限，保证两类损失项都能看到可比数量的样本。
- 训练单一压缩器版本 v1；另训练多压缩器混合版本 mix（KVzip + Expected Attention + SnapKV-context，8772 个实例）；以及直接压缩缓存训练版本 mix-cc。

## 六、主要结论与发现

1. **幻觉大幅下降、正确作答保持**：v1 适配器将基础模型的幻觉从 232 例降至 7 例（减少 97%），且在全部 8 个提示式单元格中 CONFIDENT 金标签下的正确作答率不低于基础模型（answerability preservation ratio 1.00–1.36）。
2. **学到的弃权比提示式弃权更具条件性**：仅提示的 P2 基线在 r=0.80 时对 49–51% 的 CONFIDENT 金标签示例过度弃权，而混合适配器仅过度弃权 6–10%；在 CONFIDENT 金标子集上 mix 优于 P2 的 Δ∈[+0.28, +0.34]，pooled p ≈ 1.5×10⁻¹⁶。
3. **仅展示截断文本不足以产生正确弃权**：Fragment 基线在适配器能正确弃权的 89 个例子上捕获率仅 15%（80% 仍幻觉）。
4. **混合压缩器训练弥合跨压缩器差距**：在 SnapKV-context 上，v1 迁移增量仅 +0.21，混合训练升至 +0.53；89 例跨压缩器失败中救回 82 例。
5. **压缩缓存解码下显著恢复**：未辅助基础模型在 CONFIDENT 金标上几乎崩溃（聚合 4/97，r=0.80 时 1/69）；多压缩器 cc 训练将正确作答提升至 24/97（聚合）和 22/69（r=0.80），相对提升 6–22×，Wilson 95% CI 不重叠。
6. **行为由证据内容而非输入长度驱动**：在相同输入长度的三种受控删除条件下，适配器对包含证据的掩码作答、对排除证据的掩码弃权，排除长度启发式解释。
7. **跨基座与长上下文泛化成立**：Llama-3.1-8B 复现 Δ=+0.64、幻觉减少 96%；RULER 16K 下幻觉率降低 36–43pp。

## 七、优点

- **问题形式化全新且有实用价值**：首次将 KV 压缩导致的证据丢失建模为行为学习问题，目标与表征侧方案正交互补。
- **紧密跨度设计的洞察力**：通过逐字答案跨度替代整段段落标签，解决了监督信号被稀释的核心技术障碍，使学习问题良定。
- **损失分解的清晰性**：L_CONF 与 L_ABS 的分离直接对应双向行为约束，并解释了对固定弃权先验的规避。
- **实验验证层次丰富**：从提示式推理到部署相关压缩缓存推理；从单压缩器到多压缩器；从受

控删除探针到长上下文泛化，形成了从机制理解到部署验证的完整证据链。
- **统计方法相对严谨**：配对精确检验、bootstrap 置信区间、多种子报告等做法在同类工作中较为少见，提升了结论的可信度。

## 八、缺点与局限性

- **部分关键对比统计功效不足**：r=0.50 切片上 mix 与 P2 的对比未达到显著水平（pooled p=0.17，样本量仅 37–48），作者虽坦诚承认，但这意味着"混合训练优于提示基线"的最强主张在该切片上缺乏严格统计支持。
- **压缩缓存推理验证面较窄**：仅使用 KVzipPress 一种缓存压缩实现，未在 Expected Attention、SnapKV 等压缩器的缓存模式下验证，削弱了"部署相关"结论的普适性。
- **训练数据规模与多样性有限**：核心训练集仅约 2.6K 实例、单一数据集（MuSiQue 2-hop），尽管有多压缩器混合版本补充，但整体数据量偏小，可能限制适配器在更广泛任务类型上的泛化。
- **紧密跨度定位依赖数据集注释**：需要 question_decomposition 这类结构化字段才能获得答案跨度，对无此注释的数据集无法直接复用，方法迁移存在额外成本。
- **固定拒答语句的机械性**：训练中所有 ABSTAIN 样本都映射到同一句固定拒答语，未探索让模型生成自然、可解释的拒答理由，可能影响用户体验。
- **阈值设定缺乏敏感性分析**：τ_low=0.3、τ_high=0.8 虽经实验选用，但未系统报告不同阈值组合对标签分布与最终性能的影响，读者无法判断该方法对超参数的稳健性。
- **与表征侧方案的互补关系未实证**：论文反复强调与 KV-Distill 等表征侧方法互补，但未设计联合实验量化叠加效果，互补性主张停留在概念层面。
- **验证集复用风险**：超参数选择与主结果报告共用同一验证集（虽有 100 例 disjoint 分割的复现），仍存在轻微的选择偏差隐患，且未做完整的预注册式 dev/test 分离。

## 九、潜在影响与未来研究方向

- **软弃权设计**：将目前的二元标签（作答/弃权）扩展为分级置信输出，或与表征侧保留策略结合，在证据部分存活时允许低置信作答而非直接拒答。
- **自适应保留率**：利用证据存活分数 ρ 动态决定压缩率，使压缩器在检测到关键证据濒危时主动预留更多 token，形成"压缩-弃权"闭环。
- **多跳与开放域扩展**：将方法推广到 3+ 跳推理、多文档问答与生成式任务，检验弃权决策在更长推理链中的稳健性。
- **对齐与全参微调**：将弃权信号纳入 RLHF 或 DPO 框架，或从 LoRA 扩展到全参数微调，探索是否进一步提升条件弃权的质量。
- **跨语言与多模态**：MuSiQue 为英文文本 QA，未来可考察该方法在多语言与图文混合上下文中的适用性。

## 十、总体评价与个人思考

本文的核心贡献不在模型架构，而在**问题构建**。它将 KV 压缩导致的"证据丢失→幻觉"这一工程现象，转化为一个标签定义清晰、可端到端优化的行为学习问题。紧密跨度定位这一技术细节是全文最关键的洞察——它解决了压缩掩盖下监督信号被稀释的障碍，使得学习目标良定且信息量充足。对于一个以"诚实弃权"为目标的工作而言，这种对数据标签质量的执着是值得学习的。

不过，读者也应看到其边界：训练数据规模小、统计把握度在某些切片上不足、缓存推理验证单一。它更像一篇"可行性论证"而非"产品级方案"，但其问题形式化方法为后续研究提供了坚实起点。若未来能与表征侧方案联合实验、并在更大规模多任务数据上验证，其价值还会进一步提升。
