## 摘要
大语言模型能够总结金融信息，但一个可操作的股票研究系统首先必须整合异构证据、揭示不可用数据和模型能力，并控制生成的意见如何影响最终报告。我们提出了DSA，一个用于多市场股票研究的大语言模型（LLM）代理证据感知编排框架。DSA将工作流组织为证据获取、结构化上下文构建、模型路由分析、可选角色与策略技能推理，以及基于选定上下文和诊断的报告生成。默认报告配置和可选代理配置共享证据和模型路由服务，但使用特定于配置的输出验证和风险保障。在代理配置中，核心角色输出由角色特定的解析器处理，而策略技能意见在综合前还需经过信号资格划分；分歧被明确提供给决策代理，随后进行保守的风险覆盖。参考实现包括六个区域市场路径、十五个捆绑的策略技能、托管和本地模型路由，以及多种执行和交付表面。在冻结的软件快照中，1,457项可移植的离线后端契约测试通过；其中596个案例被回顾性地映射到六个契约族，这些契约族对所报告的LLM代理架构至关重要。这一证据确立了所测试软件契约的实现在一致性，而非优越的报告质量、预测准确性或投资回报。

## Abstract
Large language models can summarize financial information, but an operational stock-research system must first assemble heterogeneous evidence, expose unavailable data and model capabilities, and control how generated opinions affect a final report. We present DSA, an evidence-aware orchestration framework for multi-market stock research with large language model (LLM) agents. DSA organizes the workflow into evidence acquisition, structured context construction, model-routed analysis, optional role and Strategy Skill reasoning, and report generation with selected context and diagnostics. A default report profile and an optional agentic profile share evidence and model-routing services but use profile-specific output validation and risk safeguards. In the agentic profile, core role outputs are processed by role-specific parsers, whereas Strategy Skill opinions undergo an additional signal-eligibility partition before synthesis; disagreement is supplied explicitly to the decision agent, followed by a conservative risk override. The reference implementation includes six regional market paths, fifteen bundled Strategy Skills, hosted and local model routes, and multiple execution and delivery surfaces. At a frozen software snapshot, a selected manifest of 1,457 portable offline backend contract tests passed; 596 cases were retrospectively mapped to six contract families central to the reported LLM-agent architecture. This evidence establishes implementation conformance for the tested software contracts, not superior report quality, forecasting accuracy, or investment returns.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将股票研究组织为“证据到报告”（evidence-to-report）的五阶段工作流，并提供两种执行配置（profile）：默认报告配置（default report profile）和代理配置（agentic profile）。两者共享证据获取和模型路由基础，但在输出验证和风险保障上分离。
- **五阶段工作流**：
  1. **证据获取**：通过市场特定适配器获取报价、K线、基本面、公告、新闻和可选情绪；若从筛选开始，则先用确定性过滤、因子评分、风险约束和可选的 LLM 重排生成候选集。支持中国大陆、香港、美国、日本、韩国和台湾六个市场，但不承诺各市场特征覆盖相同。
  2. **结构化上下文构建**：计算技术特征，构建有界证据块；将数据可用性归一化为 `available`、`missing`、`not_supported`、`fallback`、`stale`、`estimated`、`partial`、`fetch_failed` 等状态；保留来源和时间戳元数据（若提供方给出）；声明式策略输出与观测数据保持可区分。
  3. **模型与能力路由**：在研究工作流之下解析提供商特定请求格式和模型名称；支持托管服务、兼容端点、提供商特定路由和本地模型；能力准入是路由特定的，生成路由和工具能力代理路由不可互换。
  4. **可选角色推理与受控综合**：核心角色代理（技术、情报、风险、决策）通过配置化编排和角色特定解析器参与；可选策略技能（Strategy Skills）输出需经过额外的信号资格划分（signal-eligibility partition）；决策代理接收保留的角色意见、合格策略意见和显式分歧摘要；随后可能执行代理风险卫士（RiskGuard）进行保守调整。
  5. **报告与检查记录**：两种配置都渲染报告供下游客户端和通知渠道使用；若启用快照持久化，则存储选定的上下文、证据质量摘要和诊断；展示和传输层不重新定义分析结论。
- **关键公式与符号**：
  - 令 $E$ 为结构化证据上下文，$O_{core}$ 为核心角色解析后意见，$O_{ext}$ 为策略技能意见。
  - 合格扩展集：$O_{ext}^{*} = \{ o \in O_{ext} : valid\_signal(o) \}$，即只有通过信号有效性检查的策略意见才进入证据链，无效意见移入诊断。
  - 分歧摘要：$D = Disagreement(O_{core} \cup O_{ext}^{*})$。
  - 初始决策：$d_0 = Synthesize(E, O_{core}, O_{ext}^{*}, D)$。
  - 最终决策：$d_{final} = RiskGuard(d_0, risk\_context)$。在三态路径中，否决可将买入改为持有；配置降级可将买入改为持有或卖出，持有改为卖出；风险覆盖不会升级决策。
- **角色与策略技能分离**：核心角色（技术、情报、风险、决策）由配置的编排准入；策略技能是可选扩展，需通过信号资格划分。参考实现捆绑了十五个策略技能（移动平均、趋势跟踪、成交量突破、事件驱动、增长质量、预期重定价、市场主题、缠论、波浪理论等），并可能声明工具需求。外部策略包在现有权限模型下仍属“受信扩展输入”，不声称在完全沙箱中执行。

## 6. 论文的主要结论与发现

- DSA 提供了一个五阶段证据到报告的架构，可将异构市场证据、模型路由、核心角色代理、可选策略技能、分歧综合和风险控制集成在一个可重复的股票研究工作流中。
- 核心发现是**软件契约的栈一致性**：在冻结快照下，1,457 个可移植离线后端契约测试通过，其中 596 个可映射到六个契约族，从而支持“所测试组件的实现与描述一致”的结论。
- 第二个重要结论是**架构设计上的可分离性**：默认报告配置和代理配置共享证据与路由基础，但采用不同的输出验证和风险机制，这提供了未来比较质量、延迟和成本的天然实验对。
- 论文明确否定了测试证据的任何外推**：通过的契约测试不能证明报告质量更优、预测准确率更高或投资回报更好；也不能证明实时提供商数据的正确性或模型生成金融分析的事实正确性。
- 实验还暴露了依赖敏感性：运行环境使用 LiteLLM 1.89.3，因为 1.98.0 下出现提示缓存测试超时；此外原生 Windows 路径存在边界限制。

## 7. 优点

- **系统设计清晰**：将评估边界置于“软件契约行为”而非“投资性能”上，避免了金融 LLM 论文常见的过度宣称。
