## Abstract
Self-detection for Large Language Models (LLMs) seeks to evaluate the trustworthiness of the LLM’s output by leveraging its own capabilities, thereby alleviating the issue of output hallucination. However, existing self-detection approaches only retrospectively evaluate answers generated by LLM, typically leading to the over-trust in incorrectly generated answers. To tackle this limitation, we propose a novel self-detection paradigm that considers the comprehensive answer space beyond LLM-generated answers. It thoroughly compares the trustworthiness of multiple candidate answers to mitigate the over-trust in LLM-generated incorrect answers. Building upon this paradigm, we introduce a two-step framework, which firstly instructs LLM to reflect and provide justifications for each candidate answer, and then aggregates the justifications for comprehensive target answer evaluation. This framework can be seamlessly integrated with existing approaches for superior self-detection. Extensive experiments on six datasets spanning three tasks demonstrate the effectiveness of the proposed framework.

## 1. 核心问题与研究动机

- 论文关注**黑盒 API 大语言模型（LLM）的自检测任务**：即利用 LLM 自身能力评估其输出答案的可信度，以缓解幻觉（hallucination）问题。
- 现有自检测方法可归为两类范式：
  - **置信度校准（Confidence Calibration）**：如通过多重采样与聚合估计置信度，代表方法为 Self-consistency、Top-K Verbalized。
  - **自评估（Self-Evaluation）**：通过预设提示让模型判断“该答案是否正确”，代表方法为 P(True)。
- 作者指出这两类范式都存在严重局限：**仅回顾 LLM 自身生成的答案**，而 LLM 有倾向过度信任自己的生成结果，导致对**错误答案给出过高置信度**，即“过度信任（over-trust）”问题。
- 论文提出一个**更全面的自检测范式**：不应只评估 LLM 生成的单个答案，而应**考虑包含多个候选答案的完整答案空间**，通过比较多个候选答案的可信度，来纠正对错误答案的过度信任。
- 基于该范式，提出名为 **T³（Think Twice before Trusting）** 的两步框架，目标是在判断是否信任 LLM 输出之前“三思而后行”。

## 2. 方法论

### 2.1 问题形式化
- 自检测过程可表示为：
  - 答案生成：`a = LLM(p(q))`
  - 检测：`c = SD(LLM, q, a)`，其中 `c` 为检测分数。
- 论文将原有方法归纳为置信度校准和自评估两个范式，并指出它们的共同不足是仅评价 LLM 生成答案 `a`。

### 2.2 新范式：综合答案评估（Comprehensive Answer Evaluation）
- 假设问题 `q` 的答案空间中有 `N` 个候选答案 `{a_q1, ..., a_qN}`。
- 先用提示 `pe` 让 LLM 对每个 `(q, a_qi)` 给出信任度评价 `ei`。
- 再将这些评价融合进现有检测方法（如置信度校准），形成对目标答案 `a` 更审慎的检测分数。
- 论文通过基于反事实数据（counterfactual data）的初步实验验证了该思路的有效性：使用反事实问题 `q̄` 的答案标签差异，可以显著降低错误答案的检测分数，提高 AUROC。

### 2.3 T³ 框架细节
- **步骤一：反思与论证（Reflection and Justification）**
  - 使用提示 `pe`，要求 LLM 对候选答案 `a_qi` 分别生成一段“辩护理由”`ei`，尝试证明该答案是正确的。
  - 这一步利用“从问题和答案反推解释”的方式，规避 LLM 从问题生成答案时的自信任偏差。
- **步骤二：联合置信度校准（Joint Confidence Calibration）**
  - 将各候选答案的解释 `ei` 注入置信度提示 `pv`，提示 `pv` 基于 Top-K Verbalized 方法，要求 LLM 一次性输出 `K` 个最可能答案及各自概率（`K = N`）。
  - 目标答案 `a` 在 `pv` 输出中的概率即作为其最终检测分数。
  - 为缓解解释顺序导致的偏差，作者对解释顺序进行打乱并取平均（如原始顺序与逆序）。
- **与现有方法的可组合性**：
  - T³ 不排斥已有方法，可直接与 Top-K Verbalized、Prompt Ensemble（类似 CAPE）等技术结合，形成 `T³ + Top-K Verb`、`T³ + PE` 等更强变体。

## 6. 主要结论与发现

- **T³ 能显著缓解 LLM 自检测中的过度信任问题**，大部分数据集和指标上优于已有范式的方法。
- **T³ 与现有方法（Top-K Verbalized、Prompt Ensemble）组合后效果更佳**：在所有数据集三种指标上基本达到或接近最优（例如 `T³ + PE` 在 HANS 上 AUROC 达 74.5，`T³ + Top-K Verb` 在 CommonsenseQA 上 AUROC 达 85.8）。
- 偏差可视化表明：T³ 大幅降低了正确与错误实例的检测分数分布重叠，尤其能压低错误答案的置信度，从而提高区分度。
- T³ 的检测分数在实际应用（如选择性预测）中有效：弃置低置信实例后，数据集准确率可提升约 10%–30%。
- 消融实验证明：对每个候选答案生成反思式解释、联合考虑所有解释、以及打乱解释顺序都是 T³ 性能的组成部分。
- 跨模型实验显示 T³ 在 GPT-3.5、GLM-4 上基本有效；但在指令遵循能力相对一般的 Gemini 上，由于未能按要求对每个候选答案生成辩护，部分场景效果减弱。

## 7. 优点

- **观点新颖**：提出“自检测应评估更综合的答案空间”这一理念，突破了以往仅审视模型自己生成答案的框架，为克服 LLM 的自我信任偏差提供了新思路。
- **即插即用**：不需要训练任何模型，也不要求白盒访问，完全通过提示工程实现，并且可直接叠加到现有自检测方法上，实用性强。
- **可解释性较好**：先要求 LLM 为每个候选答案给出辩护理由，再联合评估，中间过程便于人类理解其置信度形成依据。
- **实验扎实**：在多任务、多数据集、多模型上进行了主实验、消融、鲁棒性和适用性分析，定性与定量结合，证据较充分。
- **应用潜力**：通过选择性预测实验证明了检测分数能大幅提升实际输出准确率，对“输出可信度预警”类场景具有应用价值。

## 8. 不足与局限

- **仅面向黑盒 API LLM**：不适用于可访问模型参数和内部概率的白盒模型，作者承认这限制了方法的更广泛适用性。
- **过度信任问题未被完全消除**：从 precision/recall 表看，recall 通常高于 precision，模型仍存在一定程度的保守/信任倾向；而部分数据集上 T³ 本身并未超过例如 CAPE，需要结合额外方法才能全面最优。
- **依赖候选答案空间的质量**：实验中多为多选题数据集，候选答案天然已知；对于开放式生成任务需要额外模型或检索来构造候选集，影响方法的迁移性和效率。
- **存在提示敏感性**：作者发现 T³ 对 `pe` 和 `pv` 的措辞较敏感，尽管方差总体可控，但并未进行系统的提示优化。
- **语言与数据覆盖有限**：实验仅使用英文数据集，不同语言上的适用性未被评估；且只随机抽取了 300 条样本，规模较小，可能会忽略长尾分布。
- **对模型指令遵循能力有一定要求**：Gemini 上的结果说明，如果 LLM 未严格执行“反思与辩护”指令，T³ 的性能会迅速退化。
- **未深入探索自检测结果的上游利用**：论文仅验证了选择性预测，并未研究如何用检测分数驱动模型自我纠错或抑制幻觉的完整闭环。
