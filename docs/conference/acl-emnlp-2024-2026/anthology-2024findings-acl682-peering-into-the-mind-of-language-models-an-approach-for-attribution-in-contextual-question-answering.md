## Abstract
With the enhancement in the field of generative artificial intelligence (AI), contextual question answering has become extremely relevant. Attributing model generations to the input source document is essential to ensure trustworthiness and reliability. We observe that when large language models (LLMs) are used for contextual question answering, the output answer often consists of text copied verbatim from the input prompt which is linked together with “glue text” generated by the LLM. Motivated by this, we propose that LLMs have an inherent awareness from where the text was copied, likely captured in the hidden states of the LLM. We introduce a novel method for attribution in contextual question answering, leveraging the hidden state representations of LLMs. Our approach bypasses the need for extensive model retraining and retrieval model overhead, offering granular attributions and preserving the quality of generated answers. Our experimental results demonstrate that our method performs on par or better than GPT-4 at identifying verbatim copied segments in LLM generations and in attributing these segments to their source. Importantly, our method shows robust performance across various LLM architectures, highlighting its broad applicability. Additionally, we present Verifiability-granular, an attribution dataset which has token level annotations for LLM generations in the contextual question answering setup.

## 论文核心问题与整体含义

- **背景**：生成式 AI 特别是 LLM 在上下文问答（Contextual Question Answering）中表现优异，能够基于输入文档回答问题，但生成的答案缺乏对来源文档的显式引用或归因（attribution）。
- **核心问题**：如何将 LLM 生成的回答片段准确归属到输入文档的原始位置，以支撑答案的可验证性（verifiability）与可信度（trustworthiness）。
- **观察现象**：在上下文问答中，LLM 的输出通常由两部分组成：
  1. 从输入文档**逐字复制**的事实片段（verbatim spans）；
  2. 模型自行生成的“粘合文本”（glue text）。
- **核心假设**：LLM 在生成时对“哪些文本是从文档中复制而来”具有某种内在的感知，这种感知编码在模型的**隐藏状态（hidden states）** 中。
- **整体贡献方向**：提出一种无需额外训练、无检索模型开销、能够进行 token 级粒度归因的新方法，揭示 LLM 生成过程的内在机制，并帮助人类验证与导航 LLM 输出。

## 论文提出的方法论

### 核心思想
- 将文档 D、问题 Q 和答案 A 拼接为一个提示词 P = D + Q + A，对模型进行单次前向传播，获取每个 token 在特定层 l 的隐藏表示 h^l。
- 利用 document token 与 answer token 隐藏表示之间的**余弦相似度**，判断：
  1. 答案中哪些 token 是从文档中提取（copy）的；
  2. 这些 token 应归属到文档中的哪个片段。

### 子任务 1：提取式输出 token 的识别
- 对答案中每个 token aᵢ，若存在某个文档 token dⱼ，满足：
  - Cosine(h^l_aᵢ, h^l_dⱼ) > θ（θ 为阈值）
  - 则判定 aᵢ 来自文档 D。
- 该任务以 token 级精确率（P）、召回率（R）和 F1 为评估指标。

### 子任务 2：提取式片段的归因
- 给定待归因的片段 S（由 n 个 token 组成），计算 S 的平均隐藏表示 h̄_S。
- 在文档中找出与 h̄_S 余弦相似度最高的“锚点 token”（anchor tokens）。
- 对每个锚点 token，在其周围扩展长度不超过 L 的候选窗口，计算每个窗口的平均表示，选择与 h̄_S 相似度最高者作为最终归属片段；若文档被分成多个证据段落，则段落分数取该段内最优窗口的相似度。
- 该任务以段落级准确率（accuracy）作为评估指标。

### 与其他方法的关键区别
- **无需微调/训练**：不改变模型参数，不破坏生成质量。
- **无需检索模型**：直接利用 LLM 自身的隐藏状态进行匹配，避免额外计算开销。
- **token 级粒度**：避免基于段落/句子的粗粒度 chunk-based 归因带来的不精确问题。

## 实验设计

### 数据集

1. **QuoteSum**
   - 人工撰写的半提取式（semi-extractive）多源问答数据集。
   - 共 4,009 个答案，对应 1,376 个不同问题，按 60%/7%/33% 拆分训练、验证、测试集。
   - 每个答案由来自多个源文档的显式提取片段拼接而成。

2. **Verifiability-Granular（V ERI-GRAN）**
   - 论文自行构建并发布，源自 Liu et al. (2023b) 的生成式搜索引擎验证数据集。
   - 将原文按句切分，过滤回答语句仅对应单一源句的样本，用 diff_match_patch 做字符匹配并映射到 token 级标注。
   - dev 集含 170,197 个标注语句，test 集含 272,320 个标注片段。
   - 该数据集提供 LLM 生成的上下文问答答案的 token 级归因标注。

### 对比基线

- **子任务 1 基线**：修改版 SEMQA 提示词 + GPT-3.5 / GPT-4 来识别答案中被复制的片段。
- **子任务 2 基线**：
  - GPT-3.5、GPT-4（基于修改版 SEMQA 提示词直接做归因）；
  - BM25（稀疏检索）、GTR（稠密检索）、MonoT5（seq2seq 排序模型）。

### 评估的 LLM
- Llama-7b、Llama-70b、Mistral-7b、Yi-6b、OPT-350m
- OPT-350m 因上下文长度为 2048，未在 V ERI-GRAN 上评测（该数据集最长 4096 token）。

## 主要结论与发现

- **方法有效**：
  - 在 QuoteSum 子任务 1 上，本文方法（F1 ≈ 0.96）优于 GPT-4（F1 ≈ 0.90）和 GPT-3.5（F1 ≈ 0.56），优于或与 GPT-4 持平；在 V ERI-GRAN 上各模型 F1 约为 0.84，与 GPT-4（0.79）相当或更优。
  - 在子任务 2 上，QuoteSum 中本文方法准确率（Mistral-7b 89.95%、Yi-6b 89.24% 等）与 GPT-4（90.59%）基本持平；V ERI-GRAN 上本文方法（约 77.3%~77.7%）显著优于 GPT-4（62.11%）和所有检索基线。
- **跨模型普适性**：不同模型族（LLaMA、Mistral、Yi、OPT）均表现出一致的有效性和相似的层内变化规律，说明隐藏状态中包含的内在归因信号是 LLM 的共性特征。
- **层间规律**：
  - 大模型在**早期层**即适合完成“判断 token 是否来自文档”的低级识别任务；
  - 需要**语义消歧**的归因在中间或较后层表现更好；
  - OPT-350m 因位置编码特性不同，最佳层次出现在中间层附近。
- **GPT 系列用于归因的不足**：GPT-3.5 在识别复制片段上召回率低（0.46）；GPT-4 虽好但仍有遗漏；且 GPT 在回答过程中可能出现幻觉性修改，影响归因的可靠性。
- **长上下文场景优势明显**：V ERI-GRAN 平均 69.1 个段落，远多于 QuoteSum 的 3.38 个段落；GPT 等基于 LLM 的归因方法在长上下文中性能明显退化（Lost in the Middle 效应），本文直接基于嵌入匹配的方法受影响较小。

## 优点

- **方法新颖且机理清晰**：从“半提取式回答”的观察出发，提出 LLM 内部隐藏状态编码了“复制来源”信息的假设并用实验加以验证，为可解释性和归因提供了新的切入视角。
- **无需额外训练**：不改变模型参数，不伤害答案生成质量；空间/时间开销都显著低于专门训练归因模型的方法。
- **免检索模型开销且支持 token 级归因**：无需 BM25/GTR 等检索系统支持，可精确定位到 token 及其原片段，避免段落/句级粗粒度归属造成的精度损失。
- **跨模型广泛适用**：在不同参数量（350m~70b）、不同架构（LLaMA、Yi、Mistral、OPT）上均表现稳定。
- **构建并发布新数据集**：V ERIFIABILITY-GRANULAR 提供较为稀缺的 token 级归因标注，对社区后续研究有贡献价值。
- **分析深入**：提供了细致的层间性能分析、消歧任务分析、超参数影响等，提升了工作的科学深度。
- **结果总体稳健且诚实**：在较难的 V ERI-GRAN 上采用了 PR 曲线视角，也未回避人类基线较高（92%以上）时的差距。

## 不足与局限

- **仅限定于逐字复制（verbatim）片段**：两个数据集（QuoteSum、V ERI-GRAN）的标注都只包含逐字复制内容；虽然附录用 paraphrase 版本的 QuoteSum 做了初步测试（各方法性能下降 1~3%），但 paraphrased 数据由 GPT-4 合成，难度提升十分有限，无法有力验证方法对改写内容的归因能力。
- **实验数据集领域有限**：仅覆盖上下文问答场景；是否适用于多跳推理、摘要、对话等其他文本生成任务尚无直接证据。
- **归因粒度评估只到“段落级”**：虽然标注达到 token 级别，但子任务 2 的准确率指标只计算是否选对源段落；更为精细的文本区间级评估尚未做。
- **人工基线规模小**：V ERI-GRAN 的人类表现仅由 4 名 NLP 从业者计算，样本规模有限，代表性可能不足。
- **GPT 作为基线时存在不稳定性**：GPT 系列在标记过程中可能篡改原始答案，虽然作者用叠加映射做了恢复，但引入额外误差的可能性无法排除。
- **阈值/层选择依赖超参数调优**：不同模型需要通过验证集搜索合适的层和阈值，实际推广时需针对每类模型重复该过程。
- **解释性仍有局限**：虽然揭示隐藏状态能有效区分复制/生成内容，但对其中的因果机制（为何隐藏状态包含这种信息）并没有给出深入的理论解释。
- **跨语言归因只是初步探索**：附录给出了西班牙语片段对应英语源文档的例子，表明方法存在跨语言扩展的潜力，但缺乏系统性的跨语言实验支撑。
- **上下文窗口限制**：OPT-350m 等小模型因上下文长度限制无法直接用于较长的真实场景（如 V ERI-GRAN），大上下文模型下的覆盖度受限于模型本身的上下文窗口能力。
